# 完整备份协议 v1

实际实现采用逻辑数据快照，替代早期文档提出的复制 SQLite 文件方案。这样避免 WAL 遗漏及跨文件切换：恢复通过同一 SQLite 事务替换全部逻辑表，数据库连接和 Schema 不切换。

## 文件组成

ZIP 包含 `manifest.json`、`data.json` 和 `media/<UUID>.jpg|png|jpeg`。清单记录格式版本 1、Schema 版本 10、UTC 创建时间、应用标识，以及每个文件的字节数与 SHA-256。JSON 包含全部账户、收支分类、流水、余额调整记录、心愿目标及存入取出记录、预算、物品、购买关联及偏好、理财产品；金额保持最小单位整数，业务日期保留本地日期文本，审计时间保留 UTC 毫秒。物品数量和单位可为空，数量及投资买入单价按十进制文本保存；种类可保存为 JSON 数组，仍兼容旧单一种类。

该文件不加密，摘要仅检测损坏，不验证来源。CSV 仅供分析，不能用于完整恢复。

## 导出

在数据库读事务中读取一致的全部表及其不可变图片引用。媒体先发布到私有目录再提交引用，已引用文件不会被原地覆盖。JSON、原图清单属于同一快照，压缩和摘要在独立 isolate 执行。拒绝缺失的原图。

v1.3.0 起导出与恢复共用 `BackupLimits`：每类逻辑记录最多 100,000 条、ZIP 最多 1002 个文件（数据、清单和 1000 张照片）、清单最多 1 MB、包含清单 UTF-8 字节在内的展开总量最多 100 MB、压缩后最多 50 MB。等于上限允许，超过上限拒绝。导出在同一读事务内先 COUNT 全部集合，再组装 JSON 和读取照片；不截断记录。超过容量的完整账本需要单独的容量设计，手工拆文件不等同于可完整恢复的备份。

## 恢复

1. 系统选择器读取文件，流式检查压缩文件不超过 50 MB；用户另行确认替换全部数据。
2. 预检 ZIP 中央目录，拒绝重复路径、目录、符号链接、绝对路径、穿越及未知文件；限制最多 1002 个文件、展开总量 100 MB、清单 1 MB。实际解压长度及摘要必须匹配。容器格式仅接受 1；接受 Schema 1–10，旧数据补齐未归档状态、空银行、默认头像、物品状态、空数量/单位、自定义类别名、空单价及空余额调整列表及空目标/进度列表；旧 retired/depleted 状态映射为 completed，保留结束日期，未知未来版本拒绝。
3. 解码逻辑快照，在隔离 SQLite 数据库重建并检查外键与全部仓库业务规则，包括金额、币种、类别、借贷还款、日期与物品购买关联；任何错误不影响当前数据库。
4. 将照片以新 UUID 写入私有目录并 flush，不覆盖现有文件。
5. 在生产数据库单一事务内删除旧逻辑行、插入全部已验证行，重新映射照片。失败回滚全部行并清理本次发布的文件。
6. Riverpod 的数据库流自动刷新。旧照片延迟清理，不要求在提交时完成文件删除。

## 中断与清理

照片发布后、数据库提交前的中断只产生无引用文件；SQLite 事务原子提交确保不会出现部分数据集。提交后的所有图片已经存在。测试注入提交前错误，验证数据库回滚和新照片清理。v1.3.0 已在独立 Android 15 / API 35 模拟器包中执行提交前强杀、重启回滚和恢复成功后重启检查，证据见 [验证记录](validation-v1.3.0.md)。断电、低内存、大包与真实设备仍待验收。

媒体清理只处理私有 `media/` 下名称符合规则、无任何物品引用、修改时间超过一天的文件；一天宽限保护尚未保存的编辑表单。清理在媒体服务首次打开时运行，删除失败下次重试。

## Schema 演进

数据库当前为 v10，快照位于 `lib/data/database/migrations/drift_schema_v10.json`。旧备份在隔离数据库中补齐字段，并将往来人迁移为应收/应付账户；验证迁移后的完整快照再恢复。余额调整须满足调整后减调整前等于差额，且差额不为零，损坏数据拒绝整批恢复。攒钱进度按业务日期和记录顺序校验，不允许任何历史节点为负；攒钱类已完成目标必须达到目标金额，心愿可独立标记实现。偏好支持明暗模式、主题和物品种类注册列表，并分别校验合法值。不支持未知未来版本，也不删除数据库来升级。

分类排序与图标同样保存在 Preferences，备份校验其列表／映射结构；重复或失效排序项不会隐藏当前分类，旧备份缺少设置时正常回退，未知图标标识显示通用图标，无需修改 Schema。键名、初始化与兼容规则见 [分类顺序与图标](category-settings.md)。

0.2.0 的资产、图表和归档新规则以 [产品调整](../product/revision-0.2.md) 为准。

Schema 10 增加账户 creditLimit、investmentProducts 产品集合，以及流水 investmentProductId / unitPrice。旧备份默认空额度、空产品列表和空产品／单价字段；恢复时先写账户和产品，再写流水，在隔离库验证分次报销回款及产品逐日剩余成本，成功后一次替换。旧版应用不能读取 Schema 10 备份，升级前保留旧版备份便于回退。

v1.8.0 增加 `recent_account_<expense|income>_<categoryId>` 字符串偏好，不改变 Schema。恢复校验键结构和非空有界账户 ID；允许指向已删除账户／分类的旧提示，记账时仅回忆当前币种的有效账户。备份缺省该偏好时正常回退。未知或非法偏好继续拒绝恢复。
