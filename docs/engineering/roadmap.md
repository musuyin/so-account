## 安卓真机验收步骤

- 归档有收支、转账及借贷的合成账户，确认退出当前资产与记账选择，历史账本仍保留；从设置查看历史并恢复，核对余额不变。取消永久删除应保留全部数据；确认删除后核对关联结算已删除，其他账户余额已重新计算，物品仍保留。关闭重开和备份恢复后重复核对。

- 安装 debug APK，添加人民币微信账户和银行卡账户，另加美元账户；确认币种和初始余额保存。
- 新增收入 100、支出 28.50，转账 20；确认月收入 100、支出 28.50、结余 71.50，转账仅改变双方余额。切换美元不混入人民币统计。
- 切换月份和日期，搜索备注并筛选分类；编辑和删除支出，确认日历、账户和统计一起刷新。设置预算后退出应用重开核对。
- 借入 200、偿还 50，确认待偿还 150；尝试偿还 151 应拒绝。借出和收回亦同；有还款时删除原始债务应拒绝。
- 添加自定义分类，记账使用后尝试删除，应明确拒绝。
- 独立添加物品，输入价格与购买日期；日均成本含购入当天。关联支出，尝试一笔支出关联多个物品，确认价格由自己填写且不自动重复分摊。
- 从相册选图、取消、拒绝权限、拍照，保存后强制停止再打开检查原图。选择照片期间模拟系统回收应用后，从“物品”恢复丢失选择。
- 删除账目检查物品仍在、关联解除；删除物品检查账目仍在。
- 导出全部 / 月 / 年明细及月 / 年分类汇总，保存到系统文件目录并用表格软件核对中文、备注换行、币种和分类合计。取消保存不应报错。
- 保存完整备份，再修改数据并确认恢复。核对账户余额、照片、日期、物品价格和关联。损坏或未来版本 ZIP 应拒绝且旧数据完整。
- 小屏手机、系统大字体、横屏及系统深浅切换，检查键盘、下拉选择、滚动、底部导航和分享面板。
- 新建心愿及攒钱目标，分别尝试存入、取出、超额取出、完成、归档和恢复；核对账户与收支保持原值，目标随完整备份恢复。
- 从账户明细核对余额组成，筛选转账两端和应收应付记录；从详情记一笔核对默认账户，调整余额后检查独立调整记录。

## 待验证 / 后续范围

Android 真机的文件提供器、权限、进程重建、强杀恢复、大包和低内存、已安装 APK 读取及系统覆盖安装；iPhone 功能和跨平台备份迁移；商店发布。当前数据库为 Schema v7，保留 v1–v6 升级路径及旧备份恢复。

暂不包含自动汇率或跨币种兑换、多照片、后台同步、云服务、OCR、维修 / 保修 / 出售。备份未加密，明文可移植。当前全量数据视图适合个人账本，极大规模需要分页和真机压力验证。
