# v1.8.0 验证记录

日期：2026-10-29。版本 1.8.0+23，数据库 Schema 10，没有结构迁移。

## 本地验证

335 项 Flutter 测试通过；Windows 跳过 1 项需要符号链接权限的既有用例，等待 Linux CI 补充。17 项 Python 工具测试及格式检查通过。

本次重点验证：

- 收入／支出、结余、每日统计、预算所用支出及净资产曲线与借入／借出／偿还／收回本金分离；统计借贷独立按日期和币种求和。
- 分类记忆只随成功新增记账事务提交，每类独立保存；编辑历史与失败保存不覆盖。选择分类后自动回忆同币种有效账户；手动选择优先，取消后不写记忆，归档及跨币种安全回退。
- 记忆偏好完整备份恢复往返；非法记忆拒绝且不影响现有账本。清空数据移除分类账户记忆，完整重置保留既有规则。
- 余额选择面板来自实时账面余额；打开金额隐私后仅显示遮罩；取消选择不改变草稿。
- 债务页仅应收／应付；统计页币种位于右上角并可切换；两行操作同样式及大字体高度一致，第二行保留半行空位；设置选项及数据管理按钮可正常打开。
- 月历在 320／360／390 像素、1.0／1.3／1.5／2.0 系统字体及浅深主题下保持七列正方形，不使用中文金额单位或换行，不缩小系统文字。宽格显示收入与支出，窄格仅显示带正负号的净额，超长数字使用省略号；大字体连一行金额也无法容纳时仅显示日期。完整收支保留在日期筛选明细、长按提示及无障碍标签中。
- 六行月份第一条流水与月历同屏；日期顶边对齐，今日圆点与选中边框独立；原有日期筛选、分类和图表钻取回归通过。

已实际查看合成数据截图：账户余额／隐私、两行操作、债务、设置、统计借贷、普通及放大文字月历、六行月份首屏。新增截图位于 `.tooling/screenshots/v180-*.png`，CI 截图 artifact 保留实际渲染。
