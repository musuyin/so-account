# 界面与无障碍验收

使用合成账户和金额。自动测试、截图目检和真机操作分别记录；测试通过不代表触感、系统键盘或文件面板已验收。

2026-10-27 的矩阵覆盖四种配色 × 浅/深模式 × 320/390 逻辑像素，文字放大 1.4 倍。`exposed_accounts_ui_test.dart` 生成账户类型、资产、月历和六行月历截图；`entry_purchase_flow_test.dart` 生成常驻计算键盘的记账页和记物弹窗。金额键盘为应用内计算键盘；系统键盘的实际弹出/遮挡仍需设备操作。

- 常用账户类别、银行、分类直接可见并能一次选择；只读类别、同币种限制、归档账户限制有效，已选项有更换入口。
- 取消记物保留旧草稿；取消页面不写入，保存/再记产生正确关系，失败保留输入。
- 月历今天、选中日期和金额热度使用独立标识；日期筛选能取消，分页不能改变月/日汇总。
- 金额隐藏时检查总览、分组、账户、tooltip 及 semantics，不能泄露原值；外币隔离保留。
- 放大文字时检查滚动、点击区域、保存栏、弹窗及键盘，不以新增缩字规则消除溢出；检查金额色彩和热度对比度。
- 检查实际生成的图片。截图不是 golden 自动认可；改变 golden 前必须目检。仅在有稳定回归价值时增加小规模 golden。

Mobile checks 与 Release workflow 在测试失败时也保留已有 `.tooling/screenshots/*.png`，并留存 expanded 测试日志。当前目检范围与结果、CI 证据见 [v1.3.0 验证](validation-v1.3.0.md)。
