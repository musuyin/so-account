# v2.0.2 验证记录

日期：2026-10-31。版本 2.0.2+27，数据库 Schema 10，无结构迁移。

## 规则

- 资产：资金账户、充值账户、理财账户、借出债务（应收款）。
- 负债：信贷账户、借入债务（应付款）。
- 报销账户独立保留，不计入上述总额。余额正负不改变账户归属；资产负余额抵扣资产，信贷账户正余额转为负负债抵扣负债，应付款保留原有待还方向。
- 账户类型界面名称统一为“理财账户”。存储标识保持兼容，旧账户、产品关联和备份无需迁移。
- 资产页总览、统计净资产曲线、Markdown 和 Excel 采用同一归属政策。曲线按各个受影响账户计算净资产变动，避免排除报销后仍沿用“所有转账不改净资产”的假设；收支仍仅按真实收入／支出汇总。

## 本地验证

完整 Flutter 回归 361 项通过，Windows 跳过 1 项既有符号链接用例；静态分析无问题，格式、差异检查和 17 项 Python 构建工具测试通过。

新增 3 项回归覆盖固定归属的全部账户类型、负资金／负充值／负借出、正余额信贷、负借入、报销排除、实际 Excel 列归属，以及曲线与账户总览的净资产一致性。已有跨零导出用例已改为资金账户始终只在资产表；生成／不生成收支的校准回滚测试继续通过。

界面回归检查“理财账户”的类型标签、已选摘要和分组，旧“投资理财”不再作为类型名称显示。四配色浅深模式、390 像素与 320 像素大字体、金额隐私、币种隔离、直接选择及保存／取消回归通过。已查看资产／负债 Excel 的负金额和固定列分组渲染。

实际 App 编码的合成 Excel 使用独立 Artifact Tool 导入，四表与公式检查通过，公式错误搜索为零。负债表只包含合成信贷和借入账户，资产表保留负资金、充值和借出；报销未进入两表。
