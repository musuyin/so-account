# v1.7.0 实施计划

日期：2026-10-29。基线：v1.6.0 / build 21。目标：v1.7.0 / build 22。

## 业务口径

- 报销采用独立的「报销垫付」「报销回款」流水，关联报销对象账户和原始垫付。垫付扣付款账户、增加待报销款；回款增加收款账户、减少待报销款。均不计收入、支出、预算。支持部分回款，禁止超额、提前回款，以及将本金改小到已回款以下。现有报销账户及借出历史保留，仍可按原流程收回。
- 理财账户内新增产品（股票、基金、保险、虚拟货币、自定义）。投资投入从同币种付款账户转入理财账户，关联具体产品；收回按投入成本转回同币种账户，不能超过该产品剩余投入。金额为资金／成本金额，单价可选，仅记录当次手填值，不计算份额、浮盈、现值或自动收益。期初成本继续保留在账户层，不伪造产品持仓。
- 信贷额度可选、非负，空值表示未设置；展示额度及账面已用／可用额度，余额与净资产口径不变，不将额度算作资产，也不做强制交易限额。

## 实施顺序

1. 数据：schema 9 → 10；账户增加可选额度；新增理财产品表；流水增加可选产品和单价；更新迁移、备份恢复、清空和删除依赖。已有数据字段默认空值，不重写旧流水。
2. 领域：扩展流水类型，统一 SQL 与 Dart 余额计算；报销原始单及分次回款校验；投资产品及剩余成本校验；已有结算／投资流水编辑删除后不能破坏成本约束。收支统计仍只使用 income / expense。
3. 入口：记一笔首行支出／收入／转账／债务，第二行报销／投资；每项直接可点。报销页可新建对象、垫付、回款；理财页可新建账户／产品、投入、收回；账户页的报销／理财摘要及对应账户明细可进入操作。
4. 界面：月历七列全部展示，取消横向滚动和「浅少、深多、可左右滑动」提示；保留收入／支出颜色图例、日期筛选、今日圆点及选中外框。窄格金额允许紧凑单位，完整金额见日期明细和无障碍文本；大字增加格高，不强制缩字。记一笔分类默认六列，大字体按可读性降列；日期／账户／记物改成带框且留间距的可换行按钮。
5. 统计及信息行：统计卡片伸展到可用宽度；环形图适配卡宽。二项内容左右对齐，三项左／中／右对齐，长文本可换行。清理各功能中用中点拼接的参数信息行，保留文本本身和无障碍含义。
6. 验证：迁移保留、垫付／部分回款／超额拦截／编辑删除、投资产品隔离／同币种／成本边界、额度验证、备份往返及旧备份、清空依赖、统计排除。渲染浅深主题、窄屏及大字体；验证直接选择、取消保存、日期筛选和金额隐私。执行格式、静态分析、全量 Flutter／Python 测试、生成一致性和签名 Android 构建。
7. 发布：补齐版本说明及验证记录；提交本轮文件（保留用户已有 .gitignore 修改），推送 main 与 v1.7.0 标签；等待发布与移动端 CI，核验公开 APK、签名、版本、清单与从 v1.6.0 的真实差分重建，记录独立证据。真机安装升级保留验收单独标识，不以主机截图代替。

## 范围边界

不接入行情、不推算当前价值；不引入跨币种投资；收益仍由用户另记收入／支出。本计划先于实现落盘，验证完成情况另记 validation-v1.7.0.md。
