## 范围与数据口径

月度 Markdown 对比、说明输入／预览／复制，动态 Income／Expense／Asset／Debt 四表 Excel，月份／年份／全部历史、币种选择、系统保存／分享，以及金额隐私。设置与统计页可进入，保留原有 CSV。

参考工作簿仅按四表、前三列和月份行结构读取，未改动源文件，未将真实账目或金额复制为默认数据或测试夹具。验证使用隔离内存数据库与合成数据。

资产与负债按月末账面余额回算，包含归档账户；账户没有期初日期，现有期初余额适用于全部历史月份。理财保持买入成本口径。该限制在导出页面、Markdown 和每张 Excel 表中明确说明。
