# 分类顺序与图标

收支分类管理、记账网格、首页分类筛选、物品种类管理、记物弹窗、物品表单共享 `AppSnapshot` 的分类解析。收支按 ID 分为支出、收入两个独立序列；物品种类按配置列表排列，将所有历史物品中遗漏的种类追加到末尾。首页监听偏好更新分类选项，不因此重新读取分页流水和月统计。

## 初始化与兼容

`expenseDefaults` / `incomeDefaults` 各自只有一份有序列表，每项包含显式稳定 ID 和名称。首次创建本地账本时，按列表插入分类并保存顺序；没有登录流程。调整默认列表位置不会改变 ID，也不会重排已有账本。物品种类的当前默认列表同样只在创建账本时写入配置。

已有账本缺少收支顺序时沿用原插入顺序。历史 2026-10-25 分类补全保留为冻结的数据迁移，与当前默认列表分离；完成标记避免反复补回用户已删除的分类。旧账本及旧备份缺少物品配置时，使用历史默认列表加历史种类回退，之后持久化。用户修改的当前默认列表不参与反复补全。

新增分类追加到对应序列末尾，改名保留位置，删除同时清理顺序和图标。物品种类改名在同一 SQLite 事务内更新配置列表、所有物品标签和图标映射；事务失败全部回滚。

## Preferences

| Key | 内容 |
| --- | --- |
| `category_order_expense` | 支出分类 ID 数组 |
| `category_order_income` | 收入分类 ID 数组 |
| `category_icons` | 收支分类 ID → 稳定图标标识 |
| `item_categories` | 有序物品种类名称数组 |
| `item_category_icons` | 物品种类名称 → 稳定图标标识 |

无需更改业务表或 Schema 版本。重复排序项去重，已删除的 ID 忽略，当前存在但未配置的分类补到末尾；不能通过排序改变分类收支类型。物品配置兼容历史最长 80 字标签，新增／编辑表单仍限制 40 字。配置最多 10000 项，与排序解析的边界一致。

备份包含这些偏好并校验结构；缺少新配置的旧备份正常回退，未知图标标识使用通用图标。64 个图标均为内置 Material 图标，无需联网。老分类没有显式图标时沿用名称映射，明确选过图标后按稳定标识显示，改名不会改变它。

## 交互

管理页长按整行上下拖动，右侧标识提示可拖动；保留点击编辑、删除入口。支出／收入使用独立重排列表，共用外层滚动。网格按从左到右、从上到下重排，提供悬浮反馈、目标占位、移动动画和边缘滚动；无障碍操作提供上移／下移。

松手后将顺序作为全局设置保存；取消拖动不保存，保存失败恢复顺序并提示。拖动不触发选择，也不修改金额、备注和记物草稿。取消记账或记物仍保留已保存的全局顺序。记物弹窗持续订阅共享快照；`未分类`作为其兼容兜底选项，参与排序时写入共享配置。

图标选择器按组直接展示中文名称和图标，支持中文／分组／英文标识搜索，显示当前选择并可取消。收支分类类型使用分段按钮；已有分类不能改变类型。
