# 素帐 SoAccount v2.0.1

- 修复导出资产与负债的历史余额算法：以导出时账户余额为基准，只逆向撤销已生成的收支、转账、借贷、报销和投资流水。
- 修改余额时未勾选「生成收支条目」的独立校准保留在当前基准中，不再当作历史交易撤销；勾选后产生的收入／支出条目正常参与统计与回滚。
- 导出页增加「核对当前账户余额」，支持按币种核对和调整。核对页遵循金额隐私；归档账户可查看，恢复后才能调整。
- Markdown 显示余额基准日期，并标注资产／负债为回滚估算；Excel 资产／负债列及说明同步标注估算口径。

请先核对当前余额。历史缺失的转账或还款仍会影响估算，应用不会自动补造流水。理财继续按买入成本处理。

版本 2.0.1+26，无数据库结构升级，沿用正式签名与自动更新。真机文件保存／分享、覆盖安装及跨版本数据保留仍需设备验收。
