# 素帐 SoAccount v2.0.2

- 资产与负债按账户类型固定归属：资产只含资金账户、充值账户、理财账户和借出债务；负债只含信贷账户和借入债务。报销账户独立保留，不计入两项总额。
- 修复账户历史余额变号后，同一账户同时出现在资产表和负债表的问题。负余额保留在原组抵扣，不再换组；信贷账户正余额作为负负债抵扣。
- 资产总览、统计净资产走势、Markdown 总结和 Excel 汇总使用一致的账户归属。
- 将账户类型“投资理财”的界面名称统一为“理财账户”，包含类型选择、已选摘要、账户分组、记账选择和归档列表；已有账户、产品和备份继续兼容。

继续使用 2.0.1 的回滚规则：余额修改未生成收支条目时只校准当前基准，生成的条目才参与统计与回滚。历史缺失流水仍影响估算。

版本 2.0.2+27，无数据库结构升级，沿用正式签名与更新通道。真机文件保存／分享、覆盖安装及跨版本数据保留仍需设备验收。
