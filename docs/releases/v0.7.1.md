# 素帐 SoAccount v0.7.1

- 界面更紧凑：首页收支、结余和预算合并展示，减少标题栏、导航、卡片和表单留白。常规字号下六行月历也能与第一笔流水同屏，月历可随时收起。
- 流水右侧菜单提供记物和删除，保留删除确认；物品属性、状态和种类采用紧凑筛选菜单，支持种类多选及一键重置。
- 修复外币分组新增账户、物品和账目时默认人民币的问题；没有对应币种账户时可直接创建。长金额、账户名称和备注适配窄屏与放大文字。
- 预算输入有误时保留内容并显示提示，支持修正后保存；修复预算进度条的无障碍异常，同日收入和支出分别显示。
- 增加晴空浅蓝、雾紫花园配色，夏日主题加入植物纹理；设置页外观选项更紧凑，浅色统一使用中性背景。
- 账户支持保存银行类型，账户币种选择移至工具栏；数据库升级到 Schema v8，继续支持旧库迁移和完整备份恢复。
- 账单导入仅处理收入和支出，忽略零金额、空账户及转账、借贷、还款等行；收入和支出分类分别关联。导入后可核对实际余额，通过独立调整记录校正，不额外生成收支。

沿用原有正式签名，提供通用和三种架构 APK。匹配旧版本精确 APK 时优先差分更新，不适用或失败时回退完整包；Android 系统安装仍需确认。升级前建议将完整备份保存到应用外。

本地通过静态检查、189 项 Flutter 测试和 14 项构建工具测试。Android 真机覆盖安装、系统键盘和文件选择体验仍待验收；不将自动测试或构建成功视为真机验证。
