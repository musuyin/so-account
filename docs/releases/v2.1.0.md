# 素帐 SoAccount v2.1.0

- 理财账户新增“更新当前资产”：手动填入理财平台显示的账户总资产，账户列表、详情和理财管理同时显示买入成本与当前资产，并在详情和管理中显示更新时间；支持零值和清除记录。
- 当前资产独立保存，不改写买入成本，不生成收支或余额调整；资产总览与统计继续按原有成本口径汇总。当前资产为最近一次手动记录，新增投入、收回或行情变化后可再次更新。
- 日历用常驻细框标记今天、粗框标记选中日期；选中今天时同时显示内外双框，并保留收支热度、金额和日期筛选。
- 记物排序改为直接可见的选项，并保存到本地。重新打开页面或应用后沿用上次选择，完整备份也会保留排序设置。

版本 2.1.0+28，数据库升级至 Schema 11，新增当前资产和更新时间两个可空字段，旧数据保持原值；支持旧库升级及 Schema 1–11 备份恢复。旧版应用不支持新备份，升级前建议保留原备份。

继续沿用正式签名和应用内更新通道。真机覆盖安装与跨版本数据保留仍需设备验收。
