# 素帐 SoAccount v1.3.0

- 修复完整备份的导出/恢复容量不一致：清单纳入展开体积，导出提前检查每类记录数量，超限给出明确错误并保留完整数据。
- 首页与账户明细改为按币种、日期和账户从 SQL 读取，长列表分批显示；月历、余额及筛选汇总保持全范围统计，排序包含唯一 ID。
- 分离记账草稿和导入工作流，保留付款/收款交换、原始借贷、取消草稿、保存失败保留与导入重试行为。
- 增加隔离的 Android 进程强杀/恢复测试入口、可手动运行的模拟器 CI，以及四配色浅深、窄屏大字的截图留存。
- 校准数据库、备份、事务边界及设备验收文档。数据库仍为 Schema 9，沿用固定正式签名。

本地、CI 与公开发布证据见 [v1.3.0 验证记录](https://github.com/musuyin/so-account/blob/main/docs/engineering/validation-v1.3.0.md)。真机覆盖安装、跨版本数据保留、系统文件/权限/低存储与 Android profile 性能仍待设备验收。
