新增应用内更新：

- 在“设置 → 应用更新”查看新版本、更新说明和安装包大小。
- 启动或回到应用时自动检查 GitHub 最新正式版，每天最多一次，可关闭。
- 应用内下载 Android 安装包，显示进度，支持取消和失败重试。
- 下载后验证文件大小和 SHA-256；安装前检查包名、版本和签名，再打开系统安装界面。
- iOS 可以查看更新说明和发布页面，无法安装 Android APK。

此版本开始使用固定的正式签名。此前 CI 产出的调试 APK 可能无法直接覆盖安装。若出现签名不同提示，请先在“设置 → 完整备份与恢复”导出 ZIP 备份并保存到应用外，确认备份文件存在后，再手动迁移安装正式版并恢复备份。不要未备份就卸载旧版本。

下载需要能访问 GitHub；不上传账本或个人数据。Android 需要允许本应用安装未知来源应用，并由用户确认安装。普通应用不提供静默安装。
