完善转账表导入，新增独立的人员借贷关系。

- 直接识别转账表的“转出账户、转入账户、手续费”，一行一笔，无需追加新列。
- 转账手续费单独计入支出，从转出账户额外扣除；预览展示金额、分类和重复提示，整批失败时回滚。
- 收支、转账分别提供 CSV 模板，默认隐藏无关的字段和默认值选择。
- “还款”由用户明确选择信贷账户转账、向他人还款或他人向我还款；混合情况支持逐行区分。
- 账户页新增“人员往来”，按人和币种查看待收回、待偿还、原始借贷及还款历史。人员与资金账户独立。
- 人员还款必须选择原始借贷，校验往来人、币种、日期及剩余本金，不自动关联第一笔。
- 明细 CSV 和完整备份保留往来人；数据库自动升级，仍支持恢复旧版本备份。

使用入口：账户 → 人员往来；设置 → 导入交易明细。

转账金额按转入金额解释，手续费另扣。例如转账 100、手续费 1，转出账户减少 101，转入账户增加 100，支出增加 1。向他人还款前需已有对应借入记录，他人还款前需已有对应借出记录。

已安装版本可在“设置 → 应用更新”检查并下载更新，正式签名保持一致。
