# 素帐 SoAccount v1.2.0

- 重做“记一笔”：顶栏固定支出、收入、转账、债务四个页签，收支分类使用圆形图标网格直接选择。
- 底部集中备注、金额和日期／账户／记物快捷入口，固定 123／456／789 计算键盘；支持退格、长按清空、计算结果和“再记”连续保存。
- “记物”改为独立弹窗设置，确认后暂存草稿，保存支出时一起创建物品并关联；取消弹窗保留此前草稿，取消记物不创建物品，普通编辑不会重复创建。
- 借入、借出、偿还借入和收回借出整合到“债务”，通过“新增借贷／偿还收回”及交换付款方、收款方选择方向；原始借贷关联与剩余本金校验保留。
- 调整新账本的初始分类顺序，优先餐饮、交通、购物等常用支出与工资、副业等常用收入；保留分类 ID，不动态重排或改变已有账本顺序。

本地 234 项 Flutter 测试、静态分析、格式及数据库生成一致性检查通过，已检查浅深主题、320 像素窄屏和大字体实际渲染。沿用固定正式签名和数据库结构，提供通用及三种架构 APK、更新清单与适用的差分更新。真机覆盖安装、键盘触感与跨版本数据保留仍待手机验收。
