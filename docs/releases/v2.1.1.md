# 素帐 SoAccount v2.1.1

- 精简月历，移除“日净支出、日净收入、今日细框、选中粗框”等底部说明，保留收支色阶、金额及日期选择。
- 理财管理和报销管理右上角新增货币切换按钮，点开可直接选择货币；按所选币种显示账户，新增账户和记账沿用当前币种。
- 管理页的成本、当前资产、产品和报销明细金额只显示数字，不再重复显示 CNY 等货币单位；继续支持金额隐藏及日元精度。
- 统一精简账户、债务、心愿、物品、统计、导出及更新页面的常驻操作说明和空状态引导，保留必要的字段名称、状态、错误及删除确认。
- 当前资产、统计环形图和趋势图、物品日均价格、借贷结算与余额核对统一省略重复币种；余额核对和归档账户顶部可选择币种。

版本 2.1.1+29，沿用 Schema 11、正式签名和应用内更新通道。
