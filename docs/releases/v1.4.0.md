# 素帐 SoAccount v1.4.0

- 收支分类与物品种类支持长按拖动排序，管理页、记账网格、记物弹窗、物品表单和首页分类筛选共用顺序，自动保存并在重启后保留。
- 支出、收入分别排序，不能通过拖动改变类型；提供无障碍上移／下移、边缘滚动、目标占位与悬浮反馈。取消拖动不改顺序，保存失败恢复并提示。
- 新增或编辑分类时可从 64 个内置图标中直接选择，按组展示中文名称并支持搜索；收支类型改用分段按钮。明确选择的图标在分类改名后继续保留。
- 排序不改变当前已选分类、金额、备注和记物草稿；取消记账仍保留已保存的全局顺序。记物弹窗持续订阅共享数据。
- 简化新账本的默认分类配置，每类只维护一份有序列表并使用固定 ID；保留已有账本的分类和顺序，补全历史物品种类。旧备份、未知图标、重复或失效排序项均有兼容处理。

数据库保持 Schema 9，沿用固定正式签名。验证结果见 [v1.4.0 验证记录](https://github.com/musuyin/so-account/blob/main/docs/engineering/validation-v1.4.0.md)。Android 真机长按与滚动冲突、覆盖安装及跨版本数据保留仍需设备验收。
