# 素帐 SoAccount v0.9.0

- 创建账户直接展示资金、信贷、充值、投资理财和债务的分组图标网格，点选渠道即可确定类型，不必逐个打开下拉框。银行、头像和币种也改为平铺选项，选择后保留明确的更换入口。
- 资产页突出净资产，总资产和总负债并列辅助展示；增加报销、债务与理财成本摘要。账户按大类分组、金额右对齐，支持折叠，并减少重复渠道小计。
- 可一键隐藏资产金额，总览、分类、账户和金额提示同步隐藏。分币种统计、负债与买入成本口径保持一致，不使用实时收益估算。
- 月历按每日净额显示收支色阶：净收入为绿色，净支出为红色，颜色越深表示当月相对金额越大。保留准确收支数值、图例、今天标识和日期筛选，选中边框不改变色阶含义。
- 适配浅深模式、窄屏和放大文字；校验金额文字在各配色的色阶背景下的对比度。账户已有流水或余额调整时，受保护的类型与币种不会因新选择界面而放开。

沿用固定正式签名及 Schema v8，提供通用和三种架构 APK、更新清单及适用的差分更新。系统安装仍需确认；真机覆盖安装和点击手感仍待验收。

本地静态检查、210 项 Flutter 测试和 14 项构建工具测试通过，覆盖四种配色、浅深模式和窄屏大字体。
