# 素帐 SoAccount v1.8.0

- 借入、借出、偿还与收回本金独立统计，不计入收入、支出、结余及预算；统计页单列借贷本金汇总。
- 统计页货币选择移至右上角，切换后按币种独立计算。
- 选择收支账户时显示当前账面余额；隐藏金额时同时隐藏选择面板余额。
- 每个收支分类记住最近一次成功新增账目使用的账户；切换分类自动选择同币种、未归档的记忆账户。手动更换仍可用，取消、失败保存及编辑历史不会覆盖记忆。
- 月历固定正方形格，金额使用纯数字、单行显示，不再使用千／万／亿。窄屏按空间显示净额，长数字省略，完整金额可点选日期或长按查看；大字体空间不足时保留日期和完整明细入口，不缩小系统文字。
- 债务页仅显示应收款和应付款，报销仍由报销入口管理。
- 记一笔的报销、投资按钮与其他操作样式和尺寸一致，第二行保留两个空位。
- 设置“常用”改为“选项”，“数据管理”改为与其他功能一致的按钮入口。

无需数据库结构升级；分类账户记忆保存在本地设置并随完整备份恢复，清空数据或重置时一并清除。
