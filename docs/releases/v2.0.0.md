# 素帐 SoAccount v2.0.0

- 新增月度 Markdown 总结：默认本月，可切换月份和币种，对比上月的收入、支出、净收入、总资产、总负债和净资产，并列出分类／账户金额、占比及增长率。
- 可填写特殊说明，追加到总结底部；支持预览、选取文字和一键复制。
- 新增 Excel 汇总导出，采用 Income、Expense、Asset、Debt 四张工作表，每月一行，分类和账户随当前账本动态生成。支持指定月份、指定年份或全部历史，支持系统保存和分享。
- 从“设置 → 导出”或统计页右上角进入；保留 CSV 明细和分类汇总导出。
- 金额隐私同步作用于 Markdown 预览与复制，包括资产金额、占比及增长率；隐藏金额时暂停 Excel 导出，显示后即可保存或分享。

不同币种分别统计，不做汇率折算。收支仅统计收入和支出，借贷本金、报销垫付／回款、转账和投资投入／收回不算收支。资产和负债包含归档账户，按各月末账面余额回算；账户没有期初日期，现有期初余额适用于全部历史月份。理财按买入成本，不生成实时净值。上月为零而本月非零时增长率显示 NULL，两月均为零时显示 0.00%。

版本 2.0.0+25，无数据库结构升级，沿用正式签名和自动更新通道。Android／iOS 真机复制、文件保存／分享、覆盖安装及跨版本数据保留仍需设备验收。
