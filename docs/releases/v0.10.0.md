# 素帐 SoAccount v0.10.0

- 账户操作新增“归档账户”和“永久删除账户”，直接展示两种操作及其影响。
- 归档保留账户的全部历史流水、借贷结算、余额调整及物品关联，退出当前资产汇总和新记账选择；历史账本、月历、统计及 CSV 仍可查询。
- 设置新增“归档账户”入口，可查看历史明细、一键恢复。恢复保留原账户、余额和全部关联，可继续记账。
- 永久删除需二次确认，清理账户及相关收支、转账、借贷、关联还款和余额调整；其他账户余额随之重新计算。物品保留，仅移除流水关联。取消不改变数据。
- 归档账户的历史流水只读，修改或继续结算前需先恢复；已打开的记账表单和导入预览也会检查归档状态，避免继续写入或静默切换账户。

数据库升级至 Schema v9，兼容旧库升级及旧备份恢复，完整备份保留账户归档状态。沿用固定正式签名，提供通用和三种架构 APK、更新清单及适用的差分更新。

本地 222 项 Flutter 测试、14 项发布工具测试、静态分析和四种配色的浅深主题与窄屏大字体截图检查通过。系统安装仍需确认，真机覆盖安装与跨版本数据保留仍待验收。
