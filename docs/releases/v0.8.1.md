# 素帐 SoAccount v0.8.1

- 支出记账新增“同步记物”开关。开启后物品内容直接在当前页展开，填写名称、选择物品类型后，可随账目一起保存，无需另开物品页面。
- 支持长期使用物、消耗品，以及可选的物品价格、数量和单位。日期与币种继承账目，价格独立记录，不重复计算支出。
- 支持关闭后重新展开继续填写；切换到非支出类型时不创建物品。账目菜单的“记物”入口也使用同页编辑流程。
- 保存账目、物品与购买关联采用同一事务，失败可修正后重试，不留下半条记录。普通编辑默认关闭开关，避免重复创建物品。

沿用原有正式签名与 Schema v8，提供通用、三种架构 APK 及适用的差分更新。系统安装仍需确认，真机覆盖安装及键盘手感待验收。

本地静态检查、201 项 Flutter 测试和 14 项构建工具测试通过。
