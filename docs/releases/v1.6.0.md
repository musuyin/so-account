# 素帐 SoAccount v1.6.0

- 配色简化为橙、绿、蓝、紫；统一纯色背景，移除植物图片。深色橙色保持橙色主色，设置选中态与应用主题共用偏好状态。
- 统一文字层级及金额字号，移除逐笔金额缩放；窄屏和大字下汇总自动重排。
- 月历采用正方形格子、统一金额字号，窄屏或大字可横向滚动；今日圆点、选中外框和金额热度分别呈现，点击可核对完整收支。
- 同日流水合并为日期卡片，显示完整筛选合计，分页加载不拆散同一天；保留编辑、记物及删除确认。
- 统计新增柱状／折线、四种收支指标、分类环形／条形排名切换，点击数值或分类可进入匹配明细，返回保留选择；币种直接可选。
- 长自定义范围自动按周／月汇总；分类颜色稳定，前五类与其他可展开；上期为零明确显示，JPY 遵循整数金额。

版本 1.6.0+21，数据库保持 Schema 9，兼容旧主题偏好和固定正式签名。本轮交付 P0 + P1；年度热力、资产分布和桑基图留待后续阶段。验证与真机边界见 [验证记录](https://github.com/musuyin/so-account/blob/main/docs/engineering/validation-v1.6.0.md)。
