# 素帐 SoAccount v1.9.0

- 新应用图标：白底文档与深绿回形针。
- 精简账单页面，筛选栏下直接显示每日账单，移除重复日期、笔数和汇总；投资投入与收回金额不再带正负号，转账继续通过账户方向标识。
- 选择账户时，余额统一显示在右侧，正余额绿色、负余额红色且保留负号，零余额中性色；金额隐私同时隐藏数值及正负配色。
- 上期收支图按收入、支出分组，相同类型的上期与本期柱子紧邻排列，使用统一刻度。
- 环形图增加外侧分类名称、占比和引导线，中心显示总金额；支持分类标签和扇区点击，保留分类展开与明细查看。
- 去掉各页面重复的“计入／不计入”说明，保留必要的输入限制和确认操作。
- 导入采用单级“类别”账单格式，提供相同表头的 Excel 与 CSV 模板，自动识别日期、收支类型、金额、类别、账户、备注；仍仅导入收入和支出，不再单独识别收入细分类。退款、报销、多币种描述及附件等附加列不额外生成交易。
- 修复部分 Excel 文件因 XML 命名空间前缀而无法读取的问题，支持原生日期单元格；继续拒绝公式与不支持的日期系统。

无需数据库结构升级，沿用现有正式签名和自动更新通道。界面及导入验证使用合成数据或隔离内存数据库；Android／iOS 真机交互、覆盖安装和跨版本数据保留仍需设备验收。
