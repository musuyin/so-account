# 素帐 SoAccount v0.6.0

- 新增差分更新：按当前安装包精确匹配补丁，下载后在本地合成、核对完整安装包摘要，并由 Android 校验签名；失败自动回退完整包。
- 新增三种 Android 架构安装包。大多数现代手机可选 arm64-v8a，应用内后续更新会自动选择适合设备的架构。通用包仍用于旧客户端升级。
- 账户按资金、信贷、充值、投资理财、债务分组，提供现金、微信、支付宝、信用卡、花呗、会员卡、基金、股票、应收款、应付款、报销等类别及各组余额。
- 投资理财记录买入成本与可选买入单价，不读取实时行情。
- 旧往来人自动归并为相应币种的应收/应付账户，保留原借贷和还款关联；支持直接创建以人名命名的债务账户。
- 新增“编辑账户 → 余额调整”：填写实际余额和可选说明，不产生账目、不影响收支或预算，独立保留调整记录并支持完整备份。资产走势从调整当天反映修正；不改写分笔借贷本金。

从 v0.5.3 或更早版本首次升级时，仍需下载完整安装包；安装本版后，后续有匹配补丁的版本即可使用差分。补丁大小取决于实际修改，缺少匹配补丁时自动下载完整包。系统覆盖安装仍需要用户确认。

数据库升级到 Schema v6，保留旧库迁移和旧备份恢复。建议升级前保存一份完整备份到应用外。

本地已通过静态检查、153 项 Flutter 自动测试、12 项构建工具测试及真实签名 APK 的差分合成验证。Android 真机覆盖安装、设备上的差分读取与 iPhone 实机体验仍待验收。
