# 素帐 SoAccount v0.7.0

- 新增心愿单与攒钱，可从账户、物品和设置页进入。记录目标金额、币种、优先级、截止日期及初始进度。
- 支持存入、取出、历史明细、误记删除、完成、归档与重新开启；防止超额取出和删除导致历史进度为负。心愿可标记已实现，攒钱目标达到金额后可完成。
- 展示目标进度、剩余金额、逾期天数及每日所需进度；支持搜索、按币种/类型/状态筛选，以及优先级/截止日期/进度排序。
- 可导出全部目标汇总或攒钱明细 CSV，覆盖所有币种和状态；取消保存不报错。
- 新增账户明细：点击账户查看期初余额、交易净变动和余额调整组成；按月、类型、备注及对方账户查找记录。可编辑流水、调整余额，并从当前账户快捷记账。
- 心愿与攒钱适配现有暖色和夏日主题，支持日夜模式、窄屏与大字体。
- Schema 升级到 v7，目标及进度随完整 ZIP 备份保存，继续支持旧库升级及旧备份恢复。

攒钱记录用于规划已有资金，不会锁定资金、自动转账或生成收入支出；实际购买请另行记账。

沿用固定正式签名，保留通用和三种架构 APK。v0.6.0 用户可在有精确匹配补丁时使用差分更新；差分不适用或失败时自动回退完整包。系统安装仍需用户确认。

本地通过静态检查、174 项 Flutter 测试及 14 项构建工具测试。Android 真机覆盖安装、文件选择与 iPhone 实机体验仍待验收。
