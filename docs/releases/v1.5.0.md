# 素帐 SoAccount v1.5.0

- 设置新增“本地数据管理”：可清空业务数据并保留分类及设置，或完全重置软件，使用当前版本默认分类和设置。
- 两项操作都会明确列出删除范围，并要求输入确认文字；取消、关闭弹窗或输入错误文字都不会执行删除。处理中和清理未完成时阻止返回其他页面写入数据。
- 数据库事务失败保留原账本与照片；文件清理中断会保存本机待清理记录，下次启动继续清理，支持明确重试，不重复删除业务表。
- 清理照片与应用内缓存，同时压缩 SQLite 数据库并清理 WAL；保护应用外备份，等待后台更新任务退出，避免旧任务在清理后写回缓存。

要完全采用新版默认分类，更新后进入 **设置 → 本地数据管理 → 重置软件**。请先将需要的完整备份保存到应用外；确认后会清空账本、物品和应用内照片。恢复旧备份会重新带回旧分类。

数据库保持 Schema 9，沿用固定正式签名。发布与设备验证边界见 [v1.5.0 验证记录](https://github.com/musuyin/so-account/blob/main/docs/engineering/validation-v1.5.0.md)。本版本不自动删除数据，须由用户进入上述入口并明确确认。
