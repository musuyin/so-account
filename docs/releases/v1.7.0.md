# 素帐 SoAccount v1.7.0

- 月历七列完整展示，取消左右滑动及浅少／深多提示；保留日期筛选、净收支色阶、今日标识和完整金额明细。窄屏使用紧凑金额，大字体按周增加格高。
- 记一笔新增第二行「报销」「投资」直接入口；日期、账户、记物改为分开的带框按钮；分类默认每行六个，大字体自动减少列数。
- 报销支持选择／创建对象、记录垫付和分次回款。垫付扣付款账户并增加待报销款，回款关联原始条目，两者均不计收入支出或预算。
- 理财账户支持创建股票、基金等具体产品，记录投入及按成本收回；单价可选，仅保存手填值，不估算现值或收益。期初持有成本继续保留在账户层。
- 账户页报销、理财摘要可进入管理；对应账户明细提供管理入口，历史报销借出条目可继续收回。
- 信贷账户可设置额度，账户页显示额度、可用额度，明细显示账面已用额度；额度不计入资产，不限制交易。
- 统计环形图及卡片填满可用宽度；分类、金额、比例分列对齐，其他多参数摘要同样改为左右或左中右布局。
- Schema 10 增量迁移保留旧数据，备份包含额度、理财产品和新增流水，支持 Schema 1–9 旧备份；归档、删除和清空纳入新增关联。

投资收回金额按投入成本填写，收益请另记收入／支出。没有接入实时行情，不自动计算份额或当前价值。
