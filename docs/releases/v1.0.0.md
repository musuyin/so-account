# 素帐 SoAccount v1.0.0

- 账户币种选择移到顶栏，支持在同分类内长按拖动账户并保存顺序；完整备份保留排序。
- 账户“…”新增“修改账户余额”：默认仅对齐余额，也可选择将差额生成收入或支出，参与统计和预算。债务账户继续仅对齐余额，保留逐笔借贷口径。
- “心愿与攒钱”统一命名为“心愿”，入口统一使用小猪存钱罐图标。
- 设置改为每行五个紧凑按钮，导出收纳到功能按钮中；系统大字体时适当换行。
- 主要页面只在顶部显示币种，精简重复文字；全局统一字体，使用三档字号并遵循系统缩放。
- 物品筛选改为可收起的平铺选项，收起后保留已选条件与清除入口。
- 记一笔固定顶部收支、转账等类型栏，底部固定金额输入与计算键盘，中间表单独立滚动；数字键盘自上而下为 123 / 456 / 789。
- 增补日常消费和收入一级分类，不添加二级分类；已有账本一次性补充，之后删除的分类不会自动恢复。

沿用本地优先、按币种独立统计和现有资产/负债/买入成本口径。兼容旧数据库与备份，沿用固定正式签名，提供通用包、ARM64 / ARM32 / x86_64 架构包、更新清单及适用的差分更新。

本地已通过 229 项 Flutter 测试、14 项发布工具测试、静态分析、格式与数据库生成一致性检查，并检查浅深主题、窄屏和大字体的实际渲染截图。真机覆盖安装、系统键盘切换、拖动手感和跨版本数据保留仍待手机验收。
