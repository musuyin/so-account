# 素帐 SoAccount v1.1.0

- 日历日期数字统一顶部对齐，有无收支时保持相同高度。
- 日历与账户页的币种选择统一移到顶栏最右侧。
- 修复账单收入分类识别：收入优先使用二级分类中的实际名称，空白时回退到类别；支出继续使用类别。
- 导入关联页的字段标签统一放在输入框上方，避免浮动标签与边框重叠。
- 取消收入与支出导入的重复识别和默认排除：所有有效记录默认选中，相同记录逐条保留，再次导入同一文件也会继续追加。

保留现有导入范围及校验规则：零金额、空账户与非收支记录仍自动忽略；无效记录需修正后导入。沿用固定正式签名与数据库结构，提供通用 APK、三种架构 APK、更新清单及适用的差分更新。

本地 230 项 Flutter 测试、静态分析及格式检查通过，已检查浅深主题、320 像素窄屏和大字体渲染。参考账单的 2646 条有效记录（含 329 条收入）完整入库，再次导入逐条追加。真机覆盖安装和跨版本数据保留仍待手机验收。
