# 日常界面调整（2026-10-25）

## 行为

- 账户列表的币种放在顶栏下拉选择；账户编辑也把币种选择放在表单首项，已有流水或余额调整时仍锁定币种。
- 心愿入口统一命名为“心愿”，使用小猪存钱罐图标。
- 设置常用功能、配色和外观默认按五列紧凑按钮排列；系统大字体时改为三列，文字不强制缩小。CSV 导出收纳到“导出”按钮，保存、分享和范围选择保留。
- 同一分类内的账户可长按拖动排序。排序跨页面重开保留，不改变账户分类；切换币种后仍保留其他币种的顺序。完整备份包含排序。
- 账户“…”新增“修改账户余额”。默认仅对齐余额，独立保留调整记录；开启“生成收支条目”后，正差额记收入、负差额记支出，分类为“余额调整”，参与收支统计和预算，不再重复写入独立调整。零差额不写记录；余额发生并发变化时要求重新核对。
- 债务账户仍仅对齐余额，不改写原始借贷和结算，也不直接生成资金收支。资金、信贷和投资账户沿用原有余额与买入成本口径。
- 主要单币种页面只在顶栏显示币种，金额省略重复币种前缀。涉及多个币种的账户选择菜单仍显示币种以免混淆；选择后的账户字段只显示名称。
- 全局使用 NotoSansSC，字号收敛为 12 / 14 / 20，遵循系统文字缩放。月历单元格高度按实际字号计算。
- 物品属性、状态和种类筛选改为平铺选项；种类支持多选，点击“收起筛选”保留条件摘要和清除入口，展开后保留原选择。
- 记一笔的顶部收支、转账等类型栏固定，金额输入与计算键盘固定在底部，中间表单独立滚动。编辑备注等字段唤起系统键盘时，暂时收起自定义键盘，保留保存按钮；系统键盘关闭后恢复金额键盘。
- 数字键盘自上而下为 123 / 456 / 789，保留计算、清空、小数和退格。
- 增补买菜、水果零食、咖啡茶饮、日用品、服饰鞋包、数码电器、旅行、宠物、美容护理、会员订阅、通讯网络、汽车养护、育儿、手续费等支出分类，以及利息、分红、租金、稿费、退款、其他收入分类。全部为一级分类。已有账本一次性补充同名缺失项，之后用户删除的分类不会重启后再次出现。

## 验证

自动测试覆盖余额双模式与并发校验、一次性分类补充、排序与备份恢复、拖动重开、固定键盘、筛选收起保留、外币选择与锁定、金额隐私、日期筛选，以及浅深主题、320 / 390 宽度和放大文字。实际渲染截图保存在本地 `.tooling/screenshots/revision-*.png`。

截图和 Android 构建不等同于真机验收。仍需在手机上确认长按手感、系统键盘切换、安全区和本机字体设置。
