# 纯色外观、日期卡片与统计

本轮实现原计划 P0 + P1。参考图只借鉴布局和交互，使用合成数据验证；没有将参考账户或金额加入应用。保留账本、账户、物品、统计、设置导航。

月历每格正方形，星期与日期在同一个横向滚动区域。日历金额统一 10 号，四位整数含符号和小数按完整宽度计算；大字或窄屏可左右滑动。超过四位整数以万为单位，日期筛选后显示完整金额；无障碍文本含币种和完整收支。当天以日期旁圆点标识，选中使用外框，净收支热度保留独立色阶。

流水按日倒序组成卡片，同日维持 date、createdAt、id 稳定排序。日期和当日收入／支出只出现在卡片头，转账明确显示转出方向。日汇总在 SQLite 对全部匹配记录求和，独立于每次 100 条的可见分页；筛选时标明筛选合计。加载更多同日合并，修改日期或删除后由数据库流重新分组。记物、编辑、删除确认与物品入口保持可用。

统计币种和近7天／月／年／自定义直接显示。趋势支持柱状、直线及收入／支出／结余／收支对比；柱形包含零基线和负结余。点击显示完整金额、币种和查看记录；展开数据列表也能逐项进入明细，明细继承日期、币种、分类和收支类型，返回保留统计状态。月按日、年按月；自定义 32–90 天按连续七天、超过 90 天按月自动汇总，首末区间裁切到实际范围。

分类使用环形或条形排名，默认前五类与其他，可展开全部。颜色由稳定分类 ID 决定；列表显示金额及占比，并可进入明细。上期对比提供并列柱图、差额和比例，上期为零明确显示新增或上期为0。

收支排除转账、借贷本金和余额调整，币种独立统计，JPY 使用整数。当前月／年仍采用完整周期，日均明确显示分母；截至今天的对齐周期、年度热力、资产分布及独立桑基视图属于后续 P2/P3。现有净资产图注明初始余额、历史收支和余额调整的推算口径，提供资产金额隐藏入口。
