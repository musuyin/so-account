# 配色与外观

设置页分别选择配色主题和外观模式，立即应用并持久保存。默认保持经典主题，升级不会自动改变已有配色。

| 配色 | 日间 | 深色 |
| --- | --- | --- |
| 经典暖白 | 暖白背景、红橙黄辅助色 | 经典 #121212 背景、蓝绿紫辅助色 |
| 夏日黄瓜花 | #F7F9EF 浅米绿背景、#426638 叶绿主色、#F4EDBD 淡黄选中区域 | #121612 深绿黑背景、浅叶绿主色、低亮度黄绿选中区域 |

外观支持跟随系统、日间模式、深色模式。两套配色均有日夜版本，金额的收入绿色、支出红色语义保留。

偏好设置 `theme` 保存明暗模式，`palette` 保存 `classic` 或 `cucumber`。旧数据没有 `palette` 时回退经典主题；完整备份支持两项设置，无需数据库迁移。

新增主题时，在 `lib/core/appearance.dart` 注册稳定 ID 和名称，在 `lib/app/theme/app_theme.dart` 添加日夜色值。页面使用 Material 颜色角色，不按主题 ID 分支。设置页自动枚举主题；备份验证同样使用注册列表。新增配色需要加入页面渲染测试，检查日夜、窄屏和大字显示。

记账表单：交易类型在顶部，分类和日期位于金额之前，金额与计算器放在底部。日期标签为“日期”，求值按钮为“=”。
