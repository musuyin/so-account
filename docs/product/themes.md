# 配色与外观

设置页直接选择颜色与模式，写入成功后立即应用并持久保存；写入失败显示错误，不修改选中态。设置与根主题使用同一个偏好流。默认使用绿色；已保存的配色继续保留。

| 配色 | 日间 | 深色 |
| --- | --- | --- |
| 橙色 | 橙色主色 | 浅橙色主色 |
| 绿色 | 绿色主色 | 浅绿色主色 |
| 蓝色 | 蓝色主色 | 浅蓝色主色 |
| 紫色 | 紫色主色 | 浅紫色主色 |

模式支持跟随系统、浅色、深色。全部使用中性纯色背景（浅色 #F5F5F5、深色 #141414），白色或深灰卡片。主题色用于按钮、选中态和重点内容；收入绿色、支出红色保持稳定。选项有图标及文字，大字时自动减少每行数量。

偏好设置 `theme` 保存明暗模式，`palette` 保存 `classic`、`cucumber`、`sky` 或 `lavender`。完整备份支持两项设置，主题无需数据库迁移。

v1.6.0 移除植物图片、加载逻辑及资源声明。文字使用 NotoSansSC；页面标题 18、卡片标题 15、正文 13、辅助说明 11；记录金额 14、汇总金额 21，金额使用等宽数字特性。不使用逐笔缩放，空间不足时重排。

新增主题时，在 `lib/core/appearance.dart` 注册稳定 ID 和名称，在 `lib/app/theme/app_theme.dart` 添加日夜色值。页面使用 Material 颜色角色。设置页与备份验证共用注册列表。测试须覆盖真实入口连续切换、页面颜色、系统明暗变化、重建、偏好恢复及八套静态外观。
