# 配色与外观

设置页分别选择配色主题和外观模式，立即应用并持久保存。没有保存过配色时默认使用夏日黄瓜花；已明确保存的配色继续保留。

| 配色 | 日间 | 深色 |
| --- | --- | --- |
| 经典暖白 | #F5F5F5 背景、淡红橙黄卡片及辅助色 | 经典 #121212 背景、蓝绿紫辅助色 |
| 夏日黄瓜花 | #F5F5F5 背景、浅叶绿卡片、淡黄选中区域 | #121612 深绿黑背景、浅叶绿主色、低亮度黄绿选中区域 |
| 晴空浅蓝 | 中性浅底、浅蓝卡片、蓝色主色 | 低亮度深底、浅蓝主色 |
| 雾紫花园 | 中性浅底、淡紫卡片、紫色主色 | 低亮度深底、浅紫主色 |

外观支持跟随系统、日间模式、深色模式。四套配色均有日夜版本，金额的收入绿色、支出红色语义保留。设置入口、外观选项和主题均采用方形按钮；大字时自动减少每行数量。

偏好设置 `theme` 保存明暗模式，`palette` 保存 `classic`、`cucumber`、`sky` 或 `lavender`。完整备份支持两项设置，主题无需数据库迁移。

夏日黄瓜花的大卡片使用 `assets/themes/cucumber-large.png`，输入框使用 `assets/themes/cucumber-small.png`。装饰绘制在文字下方，保留点击、焦点、错误提示和输入语义；深色模式降低装饰亮度。其他配色不绘制背景图。生成方式和提示词见 `assets/themes/README.md`。账本日历行高从 84 缩小为 68，大字时增加必要空间以容纳日期和收支金额。

新增主题时，在 `lib/core/appearance.dart` 注册稳定 ID 和名称，在 `lib/app/theme/app_theme.dart` 添加日夜色值。页面使用 Material 颜色角色，不按主题 ID 分支。卡片须使用 `borderOnForeground: false`，使主题装饰位于内容下层。设置页自动枚举主题；备份验证同样使用注册列表。新增配色需要加入页面渲染测试，检查日夜、窄屏和大字显示。

记账表单：交易类型在顶部，分类和日期位于金额之前，金额与计算器放在底部。日期标签为“日期”，求值按钮为“=”。
