# 财务总结与汇总导出

入口：设置 → 导出；统计页的下载按钮会带入当前月份与币种。

## 月度总结

默认当前月份，以平铺选项选择币种，用前后按钮或日期选择器切换月份。总结包含总体概况、支出明细、收入明细、资产明细和负债明细。资产／负债明确标为回滚估算，并显示余额基准日期；可先从「核对当前账户余额」调整实际余额。输入特殊说明后，点击“复制 Markdown”可粘贴到笔记或消息，也可先预览和选取文字。

分类使用当前完整分类列表及用户顺序，保留零交易分类。资产和负债按实际账户展开，包括归档账户；同名的应收、应付和报销账户用方向区分。理财账户注明买入成本。同一账户跨零时，在资产和负债表分别显示当月对应一侧的金额，另一侧为零。

金额按币种精度输出，日元没有小数。占比与增长率保留两位小数。增长率为 `(本月 - 上月) / 上月`，负数基期保留其符号；两月为零时为 `0.00%`，上月为零而本月非零时为 `NULL`。总额为零时占比为 `0.00%`。

隐藏资产金额时，总结的资产／负债／净资产金额、占比和增长率同步隐藏，预览、可选文字与剪贴板使用同一口径。用户自己填写的说明按原文追加。

## Excel 汇总

遵循参考工作簿的四表结构：

| 工作表 | 固定前三列 | 动态列 |
| --- | --- | --- |
| Income | 编号、时间、总收入 | 全部收入分类 |
| Expense | 编号、时间、总支出 | 全部支出分类 |
| Asset | 编号、时间、总资产（估算） | 实际资产账户 |
| Debt | 编号、时间、总负债（估算） | 实际负债账户 |

每月一行，编号从 0 开始。指定月份导出一行；指定年份导出 12 行，零交易月份保留。全部历史从该币种最早流水或余额调整的月份开始，至少覆盖到当前月，并包含已记录的未来流水／调整；没有历史记录时导出当前月。没有流水而只有余额调整时，以调整记录的月份确定历史范围；初始余额没有日期，不能据此判断首个历史月份。

每次保存／分享重新读取数据库，在一致事务中汇总。金额和月份存为数值／日期，日期显示为 `yyyy-mm`，合计使用动态 SUM 范围并带缓存结果；首行和前三列冻结。分类、账户名以纯文本存储，包含公式符号也不会作为公式执行。超过 Excel 列数或月份范围时明确失败，不截断数据。

不同币种各导出一个文件。系统保存取消时不提示成功；保存失败后可重试。金额隐藏时 Excel 保存／分享按钮停用，可用右上角按钮显示金额后继续。保留 CSV 明细与分类汇总入口。汇总不能替代完整备份。

## 余额与收支口径

收入和支出只包含对应交易，不把转账、借贷本金、报销垫付／回款或投资投入／收回当成收入或支出。

资产／负债以导出时账户余额为基准，再逆向撤销目标月末之后实际生成的流水对各账户的变动。收入、支出、转账、借入借出、还款、报销、投资等均沿用账本既有账户方向规则。转账同时回滚两个账户；借贷同时回滚资金账户和债务账户。

修改余额时的两种行为：

- 未勾选「生成收支条目」：只校准当前余额。独立余额调整已经体现在导出基准里，回滚过程中不再加减其差额。
- 勾选「生成收支条目」：会产生真实收入／支出流水，该条目正常参与收支统计和回滚，没有独立调整差额重复计入。

即使只导出较早月份，也会从当前余额撤销所有后续流水；不会因后续流水或余额校准在所选导出范围之外而忽略。流水以记账日期归属，已录未来条目也按日期处理。基准与流水在同一个数据库事务内读取，当前余额校准后再次导出会重新计算。

导出包含归档账户的历史与余额，避免归档动作抹去财务记录，因此可能与仅展示未归档账户的资产页不同。核对入口按所选币种展示，包含归档账户；归档账户需要先恢复才能调整。金额隐私同时隐藏核对页金额并停用调整入口。

缺失转账、还款等流水仍无法凭空还原，当前余额也必须先核对正确，因此历史资产／负债及其增长率属于回滚估算。未记录某条流水时不会推断或创建虚构交易。理财保持买入成本口径。

参考工作簿仅用于结构，未将其中的真实分类、账户或金额作为内置数据。自动验证使用合成数据和隔离数据库。
