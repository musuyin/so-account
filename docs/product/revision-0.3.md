# 素帐 0.3 调整

浅色主题统一使用 #F5F5F5 背景，保留经典暖色、夏日黄瓜花配色；主色轻度提亮，卡片及选中区域降低饱和感。深色版本继续保留。

物品使用属性固定为长期使用物、消耗品，种类支持多选，点击即选择，再次点击取消。列表种类筛选支持多选，满足任一所选种类即可显示。

设置中的“自定义物品种类”支持新增、改名、删除；改名同步所有物品，已使用的种类不能删除。历史未注册种类仍可显示、筛选及编辑。未选种类保存为未分类。

状态统一为未使用、使用中、使用完。使用完需指定结束日期，日均成本截止该日；其他状态继续按购入至今计算持有成本。新建默认使用中，用户可改为未使用。消耗品可选填数量或容量和单位，例如 500 ml；数量最多 12 位整数、6 位小数且大于零，单位最多 20 字。购入价始终是整件记录的总价。

数据库版本 3 新增数量、单位；旧状态 retired/depleted 转为 completed，保留归档日期。物品种类在原 category 字段内保存 JSON 数组，旧单一种类文本仍可读取。完整备份兼容 schema 1/2/3，包括种类设置、数量和单位。
