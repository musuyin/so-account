# 产品需求与实现范围

来源：原 PRD v0.1 及 2026-10-18 用户扩展要求。当前进入实现阶段，最新业务规则见 [实施决策](implementation-decisions.md)。用户授权按阶段直接在 main 提交及推送。

## 目标

Flutter Android / iOS 共享实现，安卓优先，本地离线记账与物品管理；不需要账户登录或后端。

## 当前能力

| 模块 | 实现 |
| --- | --- |
| 记账 | 收入、支出、转账、借入借出及还款；增删改查、日期 / 类型 / 分类 / 关键词筛选 |
| 首页 | 月历、日筛选、月收入 / 支出 / 结余及预算、历史月份、独立币种视图 |
| 账户 | 资金 / 充值 / 信贷 / 理财，银行卡 / 微信 / 支付宝等渠道，逐账户币种、初始余额与流水余额 |
| 分类与预算 | 自定义收支分类，月及币种预算；已使用分类不得删除 |
| 统计 | 分类汇总、近六个月收支、全部日期未结清往来 |
| 记物 | 独立 CRUD、搜索分类、可选购买价格 / 日期、单张照片、日均成本 |
| 关联 | 一笔支出关联多个物品；物品可关联多笔同币种购买支出；双向查看、解除、删除一致性 |
| 数据 | SQLite，CSV 明细 / 汇总、完整 ZIP 备份及确认后恢复，包含全部图片和关系 |
| 外观 | 暖白日间（红橙黄辅助色）、#121212 深色（蓝绿紫辅助色）、跟随系统 |

价格未知和零不同；物品价格独立维护。多币种不直接求和，不采用隐含汇率。转账和借贷本金不计为收入 / 支出。

## 交付边界

本地分析、自动测试和安卓 APK 构建通过。Android 真机及 iOS 构建 / 真机尚未完成，具体检查入口见 [验收路线](../engineering/roadmap.md)。完整备份实现不等于已验证手机强杀、低内存或大包恢复。

默认 CNY，支持 USD / EUR / GBP / JPY / HKD；跨币种兑换、自动汇率、云同步、多人、OCR、AI 识别、银行同步、Excel 导入、维修 / 保修 / 出售和商业化不在当前版本内。产品名称和应用标识为开发版本，正式发布前可以再确认。

0.2.0 的资产、图表和归档新规则以 [产品调整](../product/revision-0.2.md) 为准。
