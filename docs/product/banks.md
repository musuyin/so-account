# 银行类型

新增或编辑账户时，类别选为银行卡或信用卡后，可额外选择银行类型；未指定也可保存。账户页币种选择位于顶部，与账本等页面一致。

银行 ID 和中文名称由 `lib/features/ledger/domain/banks.dart` 统一注册。账户列表及详情显示银行名称，目前使用通用银行图标，不包含银行品牌 Logo。后续可按稳定 ID 增加图片资源，在 `AccountAvatar` 中集中加载。保留用户显式选择的微信、支付宝等头像。

银行类型保存在 `accounts.bank`，与账户类别、头像分别存储。切换为非银行类别后，保存时清空银行类型。Schema v8 为既有账户补齐空字符串，不猜测旧账户所属银行。完整备份保留银行类型，并兼容缺少该字段的旧备份。
