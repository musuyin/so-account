# 0.2.0 产品调整

2026-10-18 按用户的十四项反馈更新。应用中文名为“素帐”，英文名为“SoAccount”；保留原包 ID 和本地数据库位置以支持覆盖升级。安卓和 iOS 已配置中英文显示名称资源；iOS 仍需 Xcode 构建及真机验证。

## 账户

按资金 / 充值 / 信贷 / 理财账户分块，每块列出同币种总余额。顶部按币种呈现净资产、总资产和总负债，不直接累加不同币种。

总资产 = 正账户余额 + 未收回借出；总负债 = 负账户余额绝对值 + 未偿还借入；净资产 = 总资产 − 总负债。借入不增加净资产，借出转为应收也不减少净资产。信用账户负余额代表欠款，不应再把相同欠款重复登记为借入。

头像提供微信、支付宝、银行和花呗预设图标；未选择时用账户名称首个完整字符。渠道补充花呗。

## 分类与录入

默认支出：居住、水电话费、交通、普通餐饮、娱乐餐饮、购物、文化教育、周边、娱乐、游戏、健身、音乐、保险、医疗、赡养、人情、理财亏损、其他损耗、AI-Token。

默认收入：工资、补贴、副业、投资、奖金、中奖、闲置、人情、报销。

v1 升级保留已有流水或被用户改名的旧分类，移除未使用且未改名的旧内置项，再补齐新默认列表，不改变历史账目的分类 ID。

交易类型改为顶部横向单行标签（可左右滑动），收支分类使用图标网格。金额提供加减乘除键盘，乘除优先，使用有理数精确运算，在最终货币小数位上一次四舍五入。拒绝除零、负结果、不完整算式和超额金额。

## 账本

顶部收入、支出、借入、借出同排；预算与结余同排，另行放大预算“剩余”。日历只展示每日收入绿色正号、支出红色负号，保留精确金额提示，借贷不占日期标记。删除原页面顶部宣传文案。

## 统计

- 周：所选日期及前六日，固定七天；每日收支柱图、总收支、按七天计算的日均。
- 月：完整自然月的每日收支柱图、按收支切换的分类饼图、分类金额 / 上月金额 / 差额 / 增长率，以及上月与本月收支对比图。
- 年：年度支出 / 收入 / 结余，按月柱图、分类饼图、与去年比较、收支对比及净资产走势。
- 自定义：首尾日期均计入，支持最多十年；按日柱图、分类占比、上一等长区间对比及净资产走势。

支出减少 / 收入增加显示绿色，反向显示红色，不变为中性色。上期金额为零时增长率显示“-”，避免除零或虚构增长百分比。没有流水的日期补零。

净资产走势图使用该币种所有账户的初始余额，累计历史收入减支出，转账和借贷本金相互抵消。当前没有账户初始余额的生效日期，因此它是基于当前账户期初设置的历史推算，修改无流水账户初始余额会影响历史曲线。图形提供数值提示与语义描述，不仅用颜色传递信息。

## 物品

两套独立分类：使用属性为长期使用物 / 消耗品，种类默认数码产品、日用品、食物、周边、家具、衣物、其他，仍可自定义种类。

长期使用物以“报废”归档，消耗品以“用罄”归档；可选择归档日期、恢复使用。归档日期不能在未来或早于购入。未归档日均成本计算至今天，归档后固定计算至归档当天，日期包含首日。

顶部按币种汇总全部物品买入价（含归档物品），并显示各件物品日均成本之和。价格或购入日期缺失的记录不伪装为零成本，列出未录价格 / 未计算日均数量。筛选只影响列表，不改变“全部物品”的汇总口径。

列表使用圆形照片缩略图，无图时显示物品图标。列表和详情均可管理归档。

## 数据兼容与验证

数据库 Schema 升级为 v2，增加账户 avatar、物品 use_type / status / archived_on；旧物品默认长期使用、使用中。备份容器格式仍为 v1，新清单 Schema 为 2，同时接受 Schema 1 并补齐默认字段。

自动测试覆盖旧数据库实际升级、旧备份恢复、资产计算、四则精度、分类对比、历史走势、归档日期与日均，以及 390 / 320 像素、明暗主题、大字体的导航、统计切换和计算器点击。安卓图片选择、分享和跨平台文件行为仍需真机验收。
