# 紧凑界面与日常使用（2026-10-24）

## 目标与行为

优先让手机首屏同时呈现月度收支、预算、完整月历、筛选和流水。记录较多时仍然滚动；放大文字继续遵循系统设置，不强制缩小整页文字。

- 全局标题栏 48、底部导航 64；减少卡片内外边距、表单间距和筛选项留白，保存按钮保持常驻。
- 首页收支和结余合为一排，预算和剩余金额紧接其后；未设置预算时显示明确的设置入口。借入、借出有金额时显示。
- 月历默认展开，可随时收起；日期高度随文字大小增加，同日收入和支出分别显示。每日汇总一次计算，避免每格重复扫描全部流水。
- 流水保留分类、金额、日期、账户和备注摘要，点流水进入完整编辑。右侧菜单提供“记物”和带确认的“删除账目”；已有物品关联入口保留。
- 无匹配账目时可一键清除日期、类型、分类及搜索条件。
- 物品属性、状态、种类改用紧凑菜单；种类仍支持多选，已选数量可见，可一键重置。默认包含未使用物品。
- 账户、统计、目标和详情页减少间距，保留原有信息和操作。

## 功能修复

- 从某币种的账本、账户或物品页面新增记录时，表单继承该币种，避免误存到人民币分组。
- 当前币种没有可用记账账户时，提供创建对应币种账户的入口；从外币债务账户创建借贷和债务账户也继承币种。
- 记账账户选择框随实际选择更新，长名称省略展示；完整内容保留在数据中。
- 预算先在对话框中校验。输入有误时保留输入和错误说明，修正后再保存；进度条使用框架提供的数值无障碍进度。
- 长金额和长备注在窄屏中受布局约束，点记录仍可编辑全部内容。

## 验证与手机验收

自动测试包含真实 SQLite 下的外币账户、物品和账目保存，缺失外币账户创建，预算错误后修正，筛选恢复，删除取消与确认及余额回退。布局测试覆盖六行月份、同日大额收入和支出、320 像素和放大文字、日夜主题，以及原有应用流程回归。

截图来自 Flutter 渲染测试；Android 构建结果与测试输出单独报告。真机上仍需确认以下体验：

1. 月历默认展开时浏览汇总和流水，收起后能快速查看多笔记录。
2. 外币分组新增记录后返回原列表，确认金额、币种和余额。
3. 物品菜单组合筛选、多选种类和重置，操作后结果符合预期。
4. 打开键盘后填写表单并保存；检查安全区、系统字体大小和点击手感。

不改变数据库结构、金额精度、历史数据或备份格式。
