# 心愿单与攒钱

目标有心愿和攒钱两种用途，支持名称、目标金额、币种、截止日期、优先级及备注。进度由独立存入/取出记录累加，支持初始进度、历史记录和误记删除；取出及删除后任何历史日期都不能出现负进度。

这是对已有资金的计划记录，不自动转账、锁定账户资金或生成收入支出，不计入资产和预算。不保证对应账户有相应资金；实际购物仍需正常记账，避免重复记录。

心愿可手动标记已实现，攒钱目标需达到目标金额才可标记完成。归档保留全部记录，完成或归档后需先恢复进行中才能存入/取出。目标可超额完成，进度条最大显示 100%，真实累计金额保留。已有记录不能更改币种。按币种汇总进行中的目标，绝不跨币种相加。

截止日按本地日历计算，显示剩余天数或逾期；建议日攒金额按最小货币单位向上取整，并包含截止当天。此数值只是目标拆分，不是投资收益或自动扣款。

数据采用 Schema v7 的 wish_goals / goal_contributions 表，随完整 ZIP 备份保存及恢复；旧备份缺少新表时默认空列表，恢复仍为整库替换。发布前覆盖升级、备份、事务、并发取出及窄屏/深色模式。

入口位于账户、物品和设置页。列表支持搜索、币种、类型、状态筛选及优先级/截止日/进度排序；详情展示存入取出记录。右上角可导出全部币种与状态的目标汇总或攒钱明细 CSV，包含 UTF-8 BOM、公式前缀保护和换行转义。取出以独立方向列及正金额导出，便于表格统计。取消系统保存不会提示错误。
