# 记账同页记物（2026-10-25）

支出表单提供“同步记物”开关，默认关闭。开启后直接在当前表单展开物品名称、物品类型、使用属性与可选价格；消耗品可补充数量和单位。点击原有“保存”按钮，一次保存账目和一件物品，并建立购买关联。

物品名称和类型必填，类型来自配置及已有物品，也可明确选择“未分类”。购入日期和币种沿用当前账目，物品价格独立填写，留空则保持未知价格，不把整笔支出重复分配给物品。未来日期不能创建购入记录。

关闭开关后只保存账目，当前表单里的物品输入暂时保留，重新开启可继续填写。切换到收入、转账或借贷后不创建物品。退出表单不保存草稿。

新增和编辑支出都可通过开关新增一件物品；重新打开编辑默认关闭，普通编辑不会重复记物。已有物品不会因开关关闭而删除，也不会被本次新增内容覆盖。账目菜单的“记物”入口改为打开同一支出编辑表单并预先开启开关。

账目、物品及关联在同一数据库事务内保存。物品验证或关联写入失败时，新增账目、编辑账目和余额变化一并回滚；表单保留输入以供修正。保存不会额外生成第二笔支出。数据库当前使用 Schema v9，完整备份包含账户归档状态。

验证包括真实 SQLite 回滚、关联写入故障、编辑保护、可选价格、日期和币种继承，以及同页展开、开关保留草稿、非支出隐藏草稿、失败后修正、320 像素放大文字与键盘下的保存操作。截图来自 Flutter 渲染测试，真机键盘与覆盖安装仍需验收。
