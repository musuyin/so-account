# 记账时通过弹窗记物（2026-10-27）

本次交互取代此前的同页展开开关：支出表单底部快捷栏提供“记物”，点击后打开独立弹窗，填写物品名称、显式选择物品类型及使用属性，按需填写价格、数量和单位。字段随系统大字体调整，弹窗内容可滚动。

“确认记物”只暂存草稿，不创建数据；“取消”丢弃本次弹窗修改，保留此前已确认草稿。确认后快捷栏展示物品名称，可重新编辑或点“取消记物”移除草稿。收入、转账及债务不创建物品。切换为其他币种账户后需重新设置记物，避免混用价格单位。

点击“保存”或“再记”时，在同一事务中保存支出、物品和购买关联，任一失败全部回滚。物品使用支出账户的币种与支出日期，可选价格独立填写，不自动分配整笔支出。消耗品可填写正数数量和单位，长期使用物不保留消耗字段。

“再记”保存后清空金额、备注和已确认物品草稿，保留当前日期、账户、类型和分类，便于连续记录。普通编辑默认不创建新物品，已有物品关联保留。账目菜单中的“记物”入口打开支出编辑表单后自动弹出记物设置。
