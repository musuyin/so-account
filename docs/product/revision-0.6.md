# 账户、债务与更新调整

交付分三阶段，每阶段验证后独立提交和推送 main：

- 差分：保留兼容旧客户端的完整包，新增按 ABI 分发和精确旧包匹配的块复制补丁；发布前和客户端均校验合成结果，失败回退整包。
- 账户：类型下细分用户指定类别，支持自定义类别名称；投资仅记录买入成本和单价；把旧往来人按应收/应付、币种迁移为债务账户，保留原借贷及还款关联。
- 余额调整：单独记录余额修正，不创建交易流水，不改变收入、支出和预算；在资产趋势中从调整当天反映变化，保留初始余额和交易历史。

债务账户的余额表示尚待收回或偿还的金额。应收款和报销正余额计资产，应付款正余额计负债；对负余额反向计入。借入/借出记录实际资金账户和独立债务账户，偿还/收回继承原借贷账户。历史借贷不会再在账户资产之外重复加一次。

债务账户仍有分笔借贷时，结算应关联原借贷；没有分笔借贷、仅有期初债务余额的账户可与普通账户转账。资金账户到应付款表示还款，应付款到资金账户表示借入；资金账户到应收/报销表示新增待收，应收/报销到资金账户表示收回。均不计收入或支出。

投资按持有成本展示，不接行情、不计算实时盈亏。初始买入价作为期初成本余额，后续投入/取回通过转账反映；买入单价独立保存，支持最多八位小数，不把单价乘算为实时资产。
