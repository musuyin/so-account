# 设置、导入及夏日主题调整

- 设置入口、外观选项和配色改为方形按钮，普通字号四套主题可同排显示，大字模式减少列数。
- 导入分类按明细实际收支类型分组，支持按来源原名创建缺失分类。零金额明确提示不入账，空账户需要默认账户，还款需要确认含义。
- 银行卡及信用卡支持额外保存银行类型。银行名称、通用图标和稳定 ID 已接入，品牌 Logo 待补充。
- 账本日历行高由 84 缩至 68，按大字显示增加必要空间。
- 账户页的币种选择移到顶部。
- 默认主题改为夏日黄瓜花，大卡片和输入框分别使用内置图像生成工具绘制的水彩背景；另提供经典暖白、晴空浅蓝、雾紫花园。明确保存过的主题选择保留。

验证：静态分析、183 项 Flutter 测试、两份本地 XLS 的预览/事务导入/重复检测、Android debug APK 构建通过。已检查日夜配色及 320 像素窄屏、大字截图。尚未执行真实 Android 设备的文件选择和安装交互验收；本次没有发布新版本。

验收时先在测试账本中导入参考文件：核对收入分类，创建或关联原名分类，为空账户选择实际账户，逐条确认“还款”含义，再预览选择记录。已有流水中的历史错误不会自动改写，需要单独核对修正。
