# 记一笔布局与债务方向（2026-10-27）

顶栏固定四个页签：支出、收入、转账、债务，右侧显示当前账户币种。收支分类使用圆形图标与文字网格直接选择，中部内容独立滚动。底部固定备注与金额、日期／账户／记物快捷栏，以及 123／456／789 计算键盘。支持退格、长按清空和计算结果；右下角保存，“再记”可连续新增。

日期弹出日期选择器，账户按类型分组直接选择；备注与记物各自弹窗编辑，取消不影响原值。仅展示已实现的功能入口，参考图中的账本、附件、优惠等未实现功能不加入界面。

债务整合为“新增借贷”和“偿还／收回”两种模式，并明确显示当前的借入、借出、偿还借入或收回借出。两张卡分别标明付款方、收款方；中间交换按钮切换方向。借入选择应付账户，借出选择应收或报销账户；偿还与收回必须明确选择同币种的原始借贷，不能超额或早于原借贷日期。转账交换两端同币种账户。底层仍保存原有七种交易类型，既有历史、余额及统计口径保留。

常用分类采用固定初始顺序：支出优先餐饮、交通、购物、日用品；收入优先工资、副业、奖金、补贴。只调整新账本的初始插入顺序，原分类 ID 保持不变，不依据使用次数动态重排，不迁移或重排已有账本。
