# 素帐 0.4 体验优化

## 导入中的账户

确认列名和内容关联后，预览前逐个创建缺失账户。来源名称预填，类型、渠道、币种与初始余额必须明确填写。初始余额是本批最早交易之前的余额，不从文件推算。同一来源名称去重，转入账户仅从转账行识别。可先手动关联已有账户；取消创建保留导入进度，已保存的账户保留。保存返回稳定账户 ID，改名后仍能正确关联来源名称。

## 视觉与日常操作

保留经典暖色和夏日黄瓜花两种配色，浅色统一 #F5F5F5。输入区域使用更清楚的中性底和聚焦边框；导航、筛选、浮动按钮和反馈提示采用一致的圆角与间距。收入绿色、支出红色的语义保留。

所有编辑表单的保存操作常驻底部，保存期间阻止退出。搜索可一键清空。物品默认显示全部状态，支持名称、种类、备注和单位搜索，以及最近添加、名称、价格排序；筛选无结果时提供清除入口。设置按分类管理、数据与备份分组。主页增加预算进度，超支使用红色，零预算不会除零。

历史物品种类可在设置中直接改名，同步已有物品；已使用种类仍不可删除。账户新增阻止同名同币种的重复记录，既有历史重复账户不自动合并。
