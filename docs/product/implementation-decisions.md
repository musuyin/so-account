本次用户授权进入完整实现，并要求按阶段直接在 main 提交及推送，取代准备阶段的暂不实现和暂不提交约定。

## 产品规则

- Flutter 共享 Android / iOS 工程，安卓优先。Windows 无法验证 iOS 构建与签名。
- 日间背景 #FFF8F0，红、橙、黄辅助色；夜间背景 #121212，蓝、绿、紫辅助色。支持跟随系统和手动切换。
- 默认 CNY；每个账户独立币种。支持 CNY、USD、EUR、GBP、JPY、HKD。JPY 无小数，其余两位。统计、预算和导出按币种分组，不使用隐含汇率。
- 收入、支出、转账、借入、借出、偿还借入、收回借出独立记录；转账不进入收支，同币种账户间转账，跨币种兑换暂不实施。
- 借入增加现金和应付，借出减少现金并增加应收；偿还和收回通过关联原债务记账，不能超过剩余本金。
- 账户分为资金、充值、信贷、理财类型，渠道可选银行卡、微信、支付宝、现金及其他。初始余额允许负数；信贷负余额表示欠款。
- 分类自定义，已使用分类不得删除；账户有流水时不得修改币种和初始余额。账户可归档并保留历史，也可二次确认后永久删除账户及相关历史；设置提供归档查看与恢复。
- 月预算按月份和币种保存；结余为收入减支出，与账户余额分开呈现。
- 物品独立维护购入价和日期，购买关联仅允许支出。一笔支出可关联多个物品，每件物品由用户明确输入独立价格，不自动重复分配整笔金额。
- 日均成本 = 购入价 / 含购入当天的持有天数，最低一天；未知价格或日期不显示计算值，未来购买日期不允许。
- 删除账目或物品仅解除关联，不级联删除另一侧记录。已关联债务还款的原始债务需要先删除还款。
- CSV 支持全量、本月、本年明细，以及本月、本年分类汇总；金额保持十进制文本，带 UTF-8 BOM，转义引号、逗号和换行，并防止表格公式注入。
- 完整备份仍属于交付范围，导出文件不加密；恢复采用确认后的全量替换，校验失败不得改变当前数据。
