# 账户明细

账户列表点击账户进入明细；编辑和余额调整移至详情右上角。顶部展示账面余额、期初余额、全部交易净变动与余额调整合计，四者由同一份数据库快照计算。

明细包括该账户作为收付款账户、转入账户或债务账户的全部记录，并纳入独立余额调整。按月或全部时间浏览，可筛选类型、备注、分类及对方账户。筛选后的净变动仅涵盖可见结果，不把它当成全局账户余额。

应付款正余额表示尚待偿还，转入应付款减少欠款，转出增加欠款。借入借出与偿还收回分别在真实资金账户、债务账户各显示自身方向，不重复计入账本收入支出。

可点交易进入编辑，余额调整行只展示历史差额。右上角调整按钮按当前完整余额发起新的余额调整；底部记账按钮默认选中该资金账户，债务账户则进入关联该账户的借入/借出表单。每次先展示 100 条，可继续展开。
