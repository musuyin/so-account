# 账户归档与永久删除

账户列表和账户明细右上角的“账户操作”直接展示两个选项：

- **归档账户**：保留账户 ID、期初余额、全部流水、借贷结算、余额调整和物品关联。账户退出当前资产页汇总、债务账户列表及新记账、转账、借贷、导入的账户选择。历史账本、月历、统计图表和 CSV 仍保留该账户的数据，历史资产趋势也不因归档重写。
- **永久删除账户**：二次确认后，在一个事务中删除账户及涉及它的全部流水（包括转入、转出及债务账户引用）、关联借贷本金的后续结算、余额调整和流水与物品的关联。物品本身、其他账户及无关流水保留；其他账户的余额与历史统计会随删除的流水重新计算。取消确认不改变数据。

设置 → **归档账户** 可查看已归档账户，点击“历史明细”按月、全部时间或关键词浏览，点击“恢复账户”即可回到正常使用状态。恢复保留原账户 ID、余额及全部关联，不生成新流水。归档列表只展示名称、类型、渠道和币种，不展示金额。

涉及归档账户的历史流水只读；修改、删除单条历史流水或继续借贷结算前需先恢复相关账户。仓库层也会检查账户状态，阻止归档前打开的旧表单或旧导入预览继续写入。归档账户仍占用原有同币种名称，新增同名账户时提示恢复或改名。

数据库升级至 v9，旧账户默认未归档；v1–v8 升级保留原有数据。完整备份使用 schema 9，包含归档状态，恢复继续兼容旧版本备份，缺省归档状态为未归档。

自动验证覆盖数据库升级、关闭重开、备份往返、归档与恢复、删除级联与外键、导入旧预览拒绝，以及浅深主题、320px 大字体下的操作与截图。自动测试及截图不替代 Android/iOS 真机验收。
