# 人员往来

入口：账户 → 人员往来。人员以姓名或称呼标识，不作为资金账户，不要求为人员创建银行卡、余额或币种账户；同名视作同一人，需要区分时使用不同称呼。

记一笔选择借入、借出后填写独立“往来人”，可选择已有称呼。实际收付款仍关联自己的资金账户。借贷本金不计入收支统计；待收回加入资产、待偿还加入负债，沿用既有净资产计算。不同币种分别展示，不隐含汇率。

人员页按人列出待收回、待偿还，保留两个方向，不互相抵消。展开后逐笔查看原始本金、剩余本金、资金账户及还款历史；选择具体借贷再记录部分或全部还款。已结清记录可通过“包含已结清”查看。入口也提供新增借入、借出。

还款继承原始借贷的往来人，须同币种、日期不早于原始借贷、累计不超过本金。新建普通还款表单不自动选择第一笔借贷。从人员页某笔借贷进入时明确预选该笔。已有还款的原始借贷不能改换往来人；删除原始借贷仍须先处理还款。

Schema v4 为账目增加独立 counterparty 字段；旧账目默认留空，显示“未注明往来人”，不从备注中猜测。旧数据仍可编辑补充往来人；已有还款的旧记录需先处理关联记录后再修改。普通收入、支出、转账不保留此字段。完整备份及明细 CSV 均包含往来人；仍支持 Schema v1–v3 的旧备份恢复。

导入支持人员本金及明确关联到已有借贷的还款，详见[明细导入](import.md)。人员称呼不自动创建资金账户。当前不管理人员联系方式、利息、分期计划，也不自动跨借贷分配还款。
