# 债务账户与往来

入口：账户 → 债务。应付款、应收款、报销均为独立的债务账户，可使用人员或单位的姓名/称呼作为账户名称。相同名称可分别存在于应收和应付中，不同币种分开维护。

记一笔在“债务 → 新增借贷”中通过交换付款方和收款方切换借入、借出时，分别选择实际资金账户及应付/应收账户；新增往来人通过创建债务账户完成。“偿还／收回”模式按付款方向区分偿还借入和收回借出。还款继承原借贷的债务账户，必须明确选择原借贷，不能按最近日期自动匹配。账户页直接展示债务余额，净资产不再额外重复加入旧人员汇总。

应付款正余额计负债，应收款、报销正余额计资产；负余额按相反方向计入。已有分笔借贷的账户通过偿还借入/收回借出结算。仅有期初债务的账户可以与资金账户转账结算，均不计收入或支出。

Schema v5 将旧借贷按名称、方向和币种归并为债务账户，保留原本金、日期、备注和还款关联，新增账户期初余额为零，剩余金额由原记录计算。旧未命名记录归到“未注明往来人”。改名债务账户会同步关联记录的名称，不改变原借贷 ID。已有往来的账户禁止改变币种或债务方向。

完整备份和明细 CSV 保存债务账户信息。恢复旧备份时先在隔离数据库中完成归并，再验证业务规则并替换。导入可以关联已有债务账户；缺少时预填姓名并要求确认账户类别、币种及本批之前的初始待收/待还余额。
