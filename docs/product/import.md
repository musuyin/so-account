# 明细导入

入口：设置 → 导入交易明细。此功能追加交易，不替换账本；整库恢复仍使用完整备份。

流程：选择文件与工作表 → 核对列名映射 → 关联账户、收支类型和分类内容 → 预览 → 勾选明细 → 确认导入。识别“类别”等别名只是预选建议，所有列均可手动调整。未识别列可忽略；日期和金额必须关联，空白账户、类型、分类可使用用户选择的默认值。

支持 UTF-8 CSV（逗号或分号分隔、BOM、引号、转义及多行备注）与 Excel .xlsx（多个工作表、共享字符串或内联字符串、1900 系统日期序号）。首行是列名，每行是明细。上限 10 MB、10000 条、100 列，Excel 解压上限 40 MB。旧版 .xls、公式单元格、1904 日期系统须先转换为标准 .xlsx 文本/数值；不执行公式。

交易类型支持收入、支出、转账、借入、借出。还款关联请使用完整备份恢复或在应用中记录。账户按名称匹配，也可按来源内容映射到既有账户；分类按收支类型匹配，可映射到现有分类。不会自动创建账户或分类。转账要求不同的同币种账户，币种列若存在必须与账户一致。金额按最小货币单位精确解析，负值取绝对值，方向以明确显示的交易类型为准。

预览列出每行错误；错误行不可选择。按日期、金额、类型、账户、转入账户、分类、备注比较文件内和现有账目，疑似重复默认不选择，允许用户核实后手动勾选。重复检测属于提示，相同内容可能是合法的多次消费。

选中记录在同一数据库事务中保存，使用与手动记账相同的业务校验；若中途发生异常，整批回滚。用户可返回修改映射，不会写入部分数据。导入的文件不上传，也不持久保留副本。
