# 收入与支出导入

入口：设置 → 导入明细。当前只处理收入、支出，追加到现有账本。转账、还款、借入借出等非收支记录自动忽略；不提供转账模板、双端账户映射、手续费或原始借贷关联。手动记账与既有转账/借贷数据保留。

流程：选择文件和工作表 → 核对列名 → 关联账户、收支类型及分类 → 创建非空且缺失的账户 → 预览选择 → 确认导入 → 选择是否核对余额。

## 自动忽略

- 金额为零（包括负零、小数零）的行直接跳过。
- 收支账户为空或仅空白字符的行直接跳过，不再使用默认账户或要求补建账户。
- 非收支交易类型直接跳过，不能通过类型映射将明确的转账、还款或借贷记录改成收支。
- 跳过规则在创建账户、创建分类及行校验之前执行。忽略行不会创建依赖、报作错误或计入选择；预览显示忽略数量，可用“已忽略”筛选核对来源行号及原因。
- 非零且非空账户行的日期、金额、账户关联、分类、币种等错误继续逐行显示，不会隐藏或跳过。

## 关联与预览

以单级分类账单为标准，提供 Excel 和 CSV 两种模板，表头及顺序一致：日期、收支类型、金额、类别、账户、账本、退款、退款明细、优惠、备注、标签、报销账户、报销金额、报销明细、多币种、地址、创建用户、其他、附件1、附件2、附件3、附件4、附件5。Excel 工作表名为“账单”，首行就是表头，包含两条虚构收支示例；无二级分类。

自动读取日期、收支类型、金额、类别、账户、备注六列。其余列仅保留源文件布局，不额外生成退款、报销或附件记录，也不从金额中再次扣减退款或优惠。“多币种”是类似 `$ 0.01` 的原币金额描述，不是币种代码，不自动用来切换账户币种。导入金额按所关联账户的币种处理；其他文件若有独立“币种”列，仍可关联并校验。

自动识别这些字段及常用列名，每列只能关联一个字段。日期和金额必须关联；类型列为空时可指定默认收入或支出，其他未知类型可手动关联。其他交易类型不在选项内。

账户按来源名称或用户映射匹配，资金账户与债务账户分开。非空来源账户不存在时，预填名称创建账户，明确选择类型、渠道、币种并填写期初余额；取消保留导入上下文及此前已创建的账户。同一来源名包含多个币种时要求分批导入。

收入和支出统一使用单层“类别”列，不识别收入细分类或自动合并层级；常用列名“分类”仍可识别。来源文件有多级分类时，由用户先整理为最终分类名称。分类只显示对应收入或支出行实际使用的名称，同名收支分类分别关联。可明确点击按原名称创建缺失分类，在事务中补齐并保留既有映射。日期支持 `YYYY-MM-DD HH:mm`，账目保留日期部分。负金额取绝对值，方向以收入或支出类型为准；金额按币种最小单位精确解析。

预览可按全部、已选、错误、已忽略筛选，并搜索行号、日期或备注。汇总按币种和类型分开。不识别或排除重复，所有有效行默认选中；同文件内相同记录逐条保留，再次导入也逐条追加。确认时仅允许收入、支出且没有转账目标或手续费附带记录的批次；逐行复用记账业务校验，整批事务写入，失败全部回滚。

## 导入后核对余额

只有成功导入后才询问余额处理方式。可以保持当前余额并完成，也可以进入核对页逐个调整本批实际入账的账户。核对页显示实时余额，打开表单前再次读取余额及币种；用户填写真实余额，支持零和负数。

默认将余额差额写入独立余额调整表，不新增流水，不改变期初余额或收支统计。用户也可主动开启“生成收支条目”，将差额计为收入或支出，参与收支统计与预算使用额；不会再重复写入独立调整。债务账户仅支持独立调整。保存前检查余额和币种是否已变化；发生并发变化时要求重新核对，取消或未调整的账户保留原值。调整历史随完整备份保留。

## 文件与错误处理

支持 UTF-8 CSV（逗号/分号、BOM、引号及多行备注）、标准 XLSX、BIFF8 二进制 XLS、部分 UTF-8/UTF-16 SpreadsheetML 和 HTML 表格型 XLS，根据容器识别误标后缀的 XLSX。首行必须是列名；上限 10 MB、每张表 10000 行、100 列，XLS 及文本型 Excel 最多 64 张表，XLSX 解压上限 40 MB。

不执行公式、宏、脚本或外部资源。加密文件、1904 日期系统、旧版二进制或不支持的文本编码需先用 Excel/WPS 转为值及标准 XLSX。后台解析仅传递文件名与字节；取消不报错，失败原因持续显示，重选成功之前保留原工作表及映射。

## 验证

使用合成数据运行 `flutter test test/features/import_test.dart test/features/income_expense_import_test.dart test/import_income_flow_test.dart test/import_transfer_flow_test.dart`，验证 Excel/CSV 模板保存、往返解析和入库、收支共用单层类别、附加字段不改变金额或类型、非收支行忽略及提交保护。

本地参考 Excel 可用 `flutter test tool/flat_workbook_import_test.dart --dart-define=LEDGER_IMPORT_REFERENCE=<文件路径>` 检查全部记录，只写入隔离内存数据库，输出仅含行数与忽略原因。原文件及真实账户/备注不提交。旧 XLS 检查仍可运行 `tool/reference_import_test.dart`，层级需预先整理。真实 Android 文件选择与安装仍需设备验收。
