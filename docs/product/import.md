# 明细导入

入口：设置 → 导入交易明细。此功能追加交易，不替换账本；整库恢复仍使用完整备份。

流程：选择文件与工作表 → 核对列名映射及前三行示例 → 关联账户、收支类型和分类内容 → 创建缺失账户 → 预览 → 勾选明细 → 确认导入。三步界面可返回修改映射，确认按钮常驻底部，入口可保存 CSV 模板。识别“类别”等别名只是预选建议，所有列均可手动调整。未识别列可忽略；日期和金额必须关联，空白账户、类型、分类可使用用户选择的默认值。重新选择文件/工作表会清除旧映射及默认值。

支持 UTF-8 CSV（逗号或分号分隔、BOM、引号、转义及多行备注）与 Excel .xlsx（多个工作表、共享字符串或内联字符串、1900 系统日期序号）。首行是列名，每行是明细。上限 10 MB、10000 条、100 列，Excel 解压上限 40 MB。旧版 .xls、公式单元格、1904 日期系统须先转换为标准 .xlsx 文本/数值；不执行公式。

交易类型支持收入、支出、转账、借入、借出。还款关联请使用完整备份恢复或在应用中记录。账户按名称匹配，也可按来源内容映射到既有账户；分类按收支类型匹配，可映射到现有分类。预览前若存在未关联的账户，按来源名称去重并逐个打开创建表单；预填名称，要求用户明确选择类型、渠道、币种并填写初始余额。初始余额是本批最早交易之前的余额，不能自动推测为当前余额。同名同币种的新账户禁止重复创建。用户改名后仍关联原始来源名称；转入账户仅对转账识别。取消创建保留导入文件和全部映射，已保存的账户不会因取消导入而删除。同一来源账户包含多个币种时要求拆分导入。分类不自动创建。转账要求不同的同币种账户，币种列若存在必须与账户一致。金额按最小货币单位精确解析，负值取绝对值，方向以明确显示的交易类型为准。

预览列出每行错误；错误行不可选择。支持全部、已选、错误、重复筛选和行号/日期/备注搜索；筛选不改变选择，金额按币种和交易类型分别汇总。按日期、金额、类型、账户、转入账户、分类、备注比较文件内和现有账目，疑似重复默认不选择，允许用户核实后手动勾选。重复检测属于提示，相同内容可能是合法的多次消费。

选中记录在同一数据库事务中保存，使用与手动记账相同的业务校验；还会核对账户仍存在且币种与预览一致。若中途发生异常，整批回滚。用户可返回修改映射，不会写入部分数据。导入的文件不上传，也不持久保留副本。
