# 明细导入

入口：设置 → 导入交易明细。此功能追加交易，不替换账本；整库恢复仍使用完整备份。

从账户改版开始，往来人统一对应“债务 → 应收款/应付款/报销”账户。导入借入、借出时可单独关联债务账户；缺少时预填名称并要求填写本批之前的期初债务金额。实际资金账户和债务账户分别匹配，债务本金和还款均保留原关联；不会把往来人创建为银行卡等资金账户。

流程：选择文件与工作表 → 核对列名映射及前三行示例 → 关联账户、收支类型和分类内容 → 创建缺失账户 → 预览 → 勾选明细 → 确认导入。三步界面可返回修改映射，确认按钮常驻底部，入口可保存 CSV 模板。识别“类别”等别名只是预选建议，所有列均可手动调整。未识别列可忽略；日期和金额必须关联，空白账户、类型、分类可使用用户选择的默认值。重新选择文件/工作表会清除旧映射及默认值。

兼容 23 列账单导出结构，自动匹配“日期、收支类型、金额、类别、账户、备注”。收支 CSV 模板保留这 23 列原顺序；转账 CSV 模板独立使用“日期、类型、转出账户、转入账户、金额、手续费、备注、附件1–5”12 列。两种模板均使用虚构示例。未关联的账本、退款、优惠、二级分类、报销、附件等列不会被自动解释为转账字段；不要将“报销账户”关联为目标账户，除非确认其业务含义确实是转账。列名步骤默认仅显示已识别字段，可展开关联其他字段；没有空白类型或资金账户时不显示相应默认值选择。

转账按一行一笔导入：类型填写“转账”（兼容“转帐”），源账户填转出方，目标账户填转入方。兼容“账户 + 转入账户”、`source_account + target_account` 等列名。存在独立源账户时，转账优先采用该值，否则沿用“账户”；普通收支优先使用“账户”，为空时可使用源账户。二者仍为空时只有明确选择了默认账户才可导入。目标账户不能为空；自动识别到转账且未关联目标列时，列名步骤直接提示补齐。

源账户、目标账户共同参与名称关联和缺失账户收集，按名称去重，显示“收支账户 / 转账源账户 / 转账目标账户”用途。相同账户用于不同角色时只创建一次。转账不要求分类；预览显示方向箭头。两个账户必须不同且币种相同，不处理跨币种汇率。入库只生成一条 transfer 记录，通过账本余额查询同时反映扣款和入账，统计的收入/支出不包含转账。重复检测包含方向和目标账户；反方向交易不视为同一笔。

转账金额按转入金额解释，手续费额外从转出账户扣除。例如金额 100、手续费 1，转出账户减少 101，转入账户增加 100，支出增加 1。手续费仅支持非负的同币种金额；非转账的手续费须另记支出行。手续费分类优先建议既有“手续费”，否则建议“其他损耗”，用户可更改；没有合适分类则预览报错，不静默丢弃。转账及其手续费作为同一行一起选择、整批事务保存；预览分别汇总本金和手续费支出。两部分分别检测重复；只缺少一部分时可核对后补齐，部分重复也默认不选。整行均重复时仍可手动选择重复入账。手续费支出备注保留转账上下文及原备注（最长 2000 字）。

“还款”不会根据名称或账户名称自动猜测。用户须选择信贷账户还款（转账）、向他人还款（偿还借入）或他人向我还款（收回借出）；整组选择可由单行选择覆盖。逐行选择最多展示 100 行，更多记录需分批导入或在原文件类型列明确区分。未确定类型前，不收集账户或弹出创建账户表单。

人员往来不是资金账户。借入/借出可关联独立“往来人”列；当使用双端列且没有普通“账户”值时，借入/收回借出以转入方为自己的资金账户、转出方为往来人，借出/偿还借入反向解释。明确的“往来人”列优先于双端列推导。人员不会创建为银行卡等账户。还款必须逐行明确选择已有的原始借贷，或提供“原始借贷ID / 关联借贷ID”；不按金额、姓名或最近日期自动选一笔。已有往来人须匹配、币种须一致、还款不能早于借贷或超过剩余本金。尚未入库的原始借贷应先分批导入。单次预览按已有余额校验每行；同批多行累计超额会在确认入库时被拒绝，整批回滚。

支持 UTF-8 CSV（逗号或分号分隔、BOM、引号、转义及多行备注）、Excel .xlsx（共享/内联字符串）及 Excel 97–2003 二进制 .xls（BIFF8、常规/迷你流、多工作表、Unicode、SST/CONTINUE 和数值日期）。根据文件容器识别格式，兼容误标 .xls 后缀的 XLSX。还支持部分导出工具生成的 UTF-8/UTF-16 SpreadsheetML XML、HTML 表格型 .xls。首行是列名，每行是明细；不自动猜测标题行。上限 10 MB、每工作表 10000 条、100 列，XLS 及文本型 Excel 最多 64 张工作表，XLSX 解压上限 40 MB。

Excel 97 以前的二进制 XLS、GBK 等编码的文本型 XLS 请用 Excel/WPS 另存为标准 XLSX。加密文件需移除打开密码；公式请先粘贴为值；1904 日期系统需迁移到使用 1900 日期系统的工作簿。XML/HTML 中的合并单元格需先整理为普通明细表。不执行公式、宏、HTML 脚本，也不加载外部资源。

选取文件后，仅将文件名和字节数据交给独立的后台解析入口，避免页面状态跨隔离线程传递。失败原因持续显示在页面，用户可重选；取消不报错。系统读取失败包含错误码及本机文件提示，格式/编码/空文件/密码/公式错误分别说明。重新选择成功前保留原工作表与映射，不写入账本。

交易类型支持收入、支出、转账、借入、借出、偿还借入、收回借出。账户按名称匹配，也可按来源内容映射到既有账户；分类按收支类型匹配，可映射到现有分类。预览前若存在未关联的资金账户，按来源名称去重并逐个打开创建表单；预填名称，要求用户明确选择类型、渠道、币种并填写初始余额。初始余额是本批最早交易之前的余额，不能自动推测为当前余额。同名同币种的新账户禁止重复创建。用户改名后仍关联原始来源名称。取消创建保留导入文件和全部映射，已保存的账户不会因取消导入而删除。同一来源账户包含多个币种时要求拆分导入。分类不自动创建。转账要求不同的同币种账户，币种列若存在必须与账户一致。金额按最小货币单位精确解析，负值取绝对值，方向以明确显示的交易类型为准。

预览列出每行错误；错误行不可选择。支持全部、已选、错误、重复筛选和行号/日期/备注搜索；筛选不改变选择，金额按币种和交易类型分别汇总。按日期、金额、类型、账户、转入账户、分类、备注、往来人、原始借贷比较文件内和现有账目，疑似重复默认不选择，允许用户核实后手动勾选。重复检测属于提示，相同内容可能是合法的多次消费。

选中记录在同一数据库事务中保存，使用与手动记账相同的业务校验；还会核对账户仍存在且币种与预览一致。若中途发生异常，整批回滚。用户可返回修改映射，不会写入部分数据。导入的文件不上传，也不持久保留副本。
